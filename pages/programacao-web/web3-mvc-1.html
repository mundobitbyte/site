O aviso ganha um objeto

Web III — Em desenvolvimento.

Marina acabou de informar 47 minutos para a retirada. Antes de criar uma tela para ela, precisamos garantir que uma alteração no prazo não faça a página inicial dizer uma coisa e o balcão dizer outra.

Você já resolveu parte disso: as duas telas consultam a mesma função obterAtendimento(). Vamos preservar essa conquista. A nova organização ficará atrás dessa função; quem a utiliza continuará recebendo as três mensagens conhecidas.

Faça uma mudança pequena e veja o efeito

Na sua cópia final do Capítulo 2, abra src/atendimento.php. Mantenha o PHP em execução e anote onde estão nome, situação e prazo. Crie ao lado dele um arquivo chamado AvisoAtendimento.php. Usamos um nome distinto de atendimento.php para que os dois arquivos também funcionem no Windows: um arquivo descreverá o atendimento; o outro continuará oferecendo a função usada pelas telas.

Por enquanto, leia a construção central: new AvisoAtendimento("Café Aurora", true, 47). new cria um objeto. Os três valores descrevem um atendimento específico: o Café, pedidos abertos e a estimativa informada pela equipe. Um objeto reúne dados e as operações que fazem sentido para eles.

Em PHP, uma classe descreve esse conjunto. O método __construct recebe os valores na criação. $this significa “este objeto”; $this->tempoEstimado acessa o prazo dele. Não é um novo servidor, banco ou serviço de nuvem: é uma organização do PHP que você já executa.

Conferir src/AvisoAtendimento.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
/** A regra do Café recebe valores e prepara as mensagens dos consumidores. */
class AvisoAtendimento
{
    public string $nomeNegocio;
    public bool $pedidosAbertos;
    public ?int $tempoEstimado;

    public function __construct(string $nomeNegocio, bool $pedidosAbertos, ?int $tempoEstimado)
    {
        if (trim($nomeNegocio) === "" || mb_strlen($nomeNegocio) > 100) {
            throw new InvalidArgumentException("Informe um nome de até 100 caracteres.");
        }
        if ($tempoEstimado !== null && ($tempoEstimado < 0 || $tempoEstimado > 240)) {
            throw new InvalidArgumentException("Informe de 0 a 240 minutos ou ausência de estimativa.");
        }
        $this->nomeNegocio = $nomeNegocio;
        $this->pedidosAbertos = $pedidosAbertos;
        $this->tempoEstimado = $tempoEstimado;
    }

    public function mensagens(): array
    {
        if (!$this->pedidosAbertos) {
            $situacao = "Pedidos para retirada estão encerrados.";
            $tempo = "Consulte novamente durante o horário de atendimento.";
        } elseif ($this->tempoEstimado === null) {
            $situacao = "Pedidos para retirada estão abertos.";
            $tempo = "Consulte a equipe para saber o prazo de retirada.";
        } else {
            $situacao = "Pedidos para retirada estão abertos.";
            $tempo = "Tempo estimado: {$this->tempoEstimado} minutos.";
        }
        return ["nomeNegocio" => $this->nomeNegocio, "mensagemStatus" => $situacao, "mensagemTempo" => $tempo];
    }
}

Não tente memorizar o arquivo inteiro. Primeiro encontre as três propriedades, depois o construtor e, por último, mensagens(). public permite o acesso às propriedades neste primeiro exemplo; string e bool indicam os tipos. Em ?int, o ponto de interrogação permite inteiro ou null. Aqui há verificação em tempo de execução no PHP; os tipos do TypeScript não protegem um formulário enviado diretamente ao servidor.

O construtor também recusa nome vazio e prazo fora de 0 a 240 minutos. Esse intervalo é uma regra combinada para nosso exercício, não um limite do PHP. Uma exceção interrompe a criação de um objeto inválido. Na tela da equipe, aprenderemos a transformar essa recusa em uma orientação compreensível.

Mude a organização sem mudar a resposta

Agora atualize a função conhecida. Ela inclui a classe, cria o objeto e pede suas mensagens:

Conferir src/atendimento.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
require_once __DIR__ . "/AvisoAtendimento.php";

function obterAtendimento(): array
{
    $atendimento = new AvisoAtendimento("Café Aurora", true, 30);
    return $atendimento->mensagens();
}

O arquivo de referência começa com 30 minutos para manter a base conhecida. Troque apenas esse valor por 47, salve e consulte http://localhost:8000/api/atendimento.php. Depois consulte o balcão e recarregue a página inicial. As duas apresentações devem concordar. Alteramos PHP: não há motivo para reconstruir o TypeScript.

Experimente 0, depois null e, por fim, pedidos encerrados com false. Observe a ordem das decisões em mensagens(): fechar os pedidos tem prioridade sobre informar um prazo. Não basta o programa aceitar os tipos; a mensagem precisa fazer sentido para quem vai retirar o pedido.

Uma verificação que pode ser repetida

Na pasta tests, crie atendimento-test.php. O teste faz as mesmas perguntas que você acabou de conferir, sem abrir cada tela:

Conferir tests/atendimento-test.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
require_once dirname(__DIR__) . '/src/AvisoAtendimento.php';
function conferir(bool $condicao, string $nome): void {
    if (!$condicao) { throw new RuntimeException('Falhou: '.$nome); }
    echo 'Passou: '.$nome, PHP_EOL;
}
$dados = (new AvisoAtendimento('Café Aurora', true, 47))->mensagens();
conferir(array_keys($dados) === ['nomeNegocio','mensagemStatus','mensagemTempo'], 'contrato de três campos');
conferir(str_contains($dados['mensagemTempo'], '47 minutos'), 'estimativa informada pela equipe');
conferir(str_contains((new AvisoAtendimento('Café Aurora', true, 0))->mensagens()['mensagemTempo'], '0 minutos'), 'zero não é ausência');
conferir(str_contains((new AvisoAtendimento('Café Aurora', true, null))->mensagens()['mensagemTempo'], 'Consulte a equipe'), 'ausência não inventa prazo');
conferir(str_contains((new AvisoAtendimento('Café Aurora', false, 47))->mensagens()['mensagemStatus'], 'encerrados'), 'fechamento tem prioridade');
foreach ([['',true,30],['Café Aurora',true,-1],['Café Aurora',true,241]] as $entrada) {
    $recusou=false;
    try { new AvisoAtendimento(...$entrada); } catch (InvalidArgumentException) { $recusou=true; }
    conferir($recusou, 'recusa de configuração inválida');
}

No terminal, na raiz da aplicação, execute php tests/atendimento-test.php. Cada “Passou” corresponde a uma condição verificada. Uma falha precisa ser investigada; não apague a condição apenas para obter uma mensagem verde. O teste não verifica a aparência das telas nem substitui a consulta no navegador.
