Encontrar sem perder a lista

Web III — Em desenvolvimento.

O cardápio aparece, mas o cliente quer apenas uma bebida. Já temos os dados no navegador. Consultar novamente o servidor a cada mudança do filtro seria trabalho sem necessidade para esta lista pequena.

Vamos guardar a busca e a categoria como estados e calcular a lista visível a partir deles. A lista recebida continuará preservada; filtrar não deve apagar produtos.

Combine as duas perguntas

Um produto precisa corresponder à categoria escolhida e ao texto procurado. A função abaixo devolve uma nova lista com os itens que passam pelos dois critérios.

Conferir cliente-balcao/src/regras.ts

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import type { Produto } from "./servicos/api.js";

export function filtrarProdutos(produtos: Produto[], busca: string, categoria: string): Produto[] {
  const termo = busca.trim().toLocaleLowerCase("pt-BR");
  return produtos.filter(p => (categoria === "todas" || p.categoria === categoria) &&
    p.nome.toLocaleLowerCase("pt-BR").includes(termo));
}

export function conferirDescricao(texto: string): string {
  const descricao = texto.trim();
  if (descricao.length < 10 || descricao.length > 400) throw new Error("Escreva de 10 a 400 caracteres.");
  return descricao;
}

filter seleciona sem modificar a lista original. trim retira espaços do começo e do fim. A conversão para minúsculas permite que “CAFÉ” encontre “Café”; ela não remove acentos. Busque “Café” com acento para conferir o comportamento que construímos, sem prometer uma pesquisa mais ampla.

A mesma função será útil para os testes automatizados depois. Por enquanto, vamos observar seu efeito na interface com dados reais do nosso serviço.

import type { Produto } from "../servicos/api.js";
import { filtrarProdutos } from "../regras.js";

interface Props { produtos: Produto[]; busca: string; categoria: string; aoBuscar: (v: string) => void; aoCategorizar: (v: string) => void }

export function Cardapio({ produtos, busca, categoria, aoBuscar, aoCategorizar }: Props) {
  const filtrados = filtrarProdutos(produtos, busca, categoria);
  return <section aria-labelledby="titulo-cardapio"><h2 id="titulo-cardapio">Cardápio do Café</h2>
    <p><label htmlFor="busca">Buscar produto</label><input id="busca" value={busca} onChange={e => aoBuscar(e.target.value)} /></p>
    <p><label htmlFor="categoria">Categoria</label><select id="categoria" value={categoria} onChange={e => aoCategorizar(e.target.value)}>
      <option value="todas">Todas</option><option value="bebida">Bebidas</option><option value="comida">Comidas</option>
    </select></p>
    <p role="status">{filtrados.length} produto(s) encontrado(s).</p>
    <div className="produtos">{filtrados.map(p => <article key={p.id}>
      <img src={`img/${p.imagem}`} alt={p.alt} width="240" height="160" />
      <h3>{p.nome}</h3><p>{p.descricao}</p>
      <p>{new Intl.NumberFormat("pt-BR", { style: "currency", currency: "BRL" }).format(p.precoCentavos / 100)}</p>
      {!p.disponivel && <p>Indisponível neste momento.</p>}
    </article>)}</div>
  </section>;
}

Faça uma busca que encontra e outra que não encontra

Faça o build, consulte o cardápio e digite “CAFÉ”. Selecione “Bebidas”: o café continua aparecendo. Depois selecione “Comidas”: a combinação não encontra produtos. Apague a busca e volte a “Todas”: os três itens precisam reaparecer sem uma nova consulta.

O campo recebe value do estado e comunica a alteração por onChange. Assim a apresentação e os critérios permanecem sincronizados. A quantidade de resultados está em uma região de status; zero resultados é uma resposta possível, não uma falha da rede.

Abra a aba Rede do navegador antes de digitar novamente. Para esta experiência, a busca trabalha sobre a lista recebida; não deve aparecer um pedido HTTP a cada tecla. Se o catálogo fosse muito grande ou dependesse de paginação, a decisão precisaria ser revista.

Filtrar não é perder informação

Confirme combinação de nome e categoria, nenhum resultado e recuperação da lista completa. Use os controles com teclado e confira seus rótulos. O balcão começa a acumular áreas; a próxima etapa organizará a navegação entre atendimento e cardápio.
