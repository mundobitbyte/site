Web III — Em desenvolvimento.

Uma visitante consegue abrir a página, mas não compreende as mensagens em português. O atendimento não mudou de nome, situação ou prazo; o que precisa mudar é a forma de apresentar essas informações.

Vamos traduzir uma tela primeiro. Traduzir todo o site de uma vez esconderia o que estamos aprendendo e criaria uma promessa de cobertura que ainda não cumprimos. A API usada pelo balcão continuará com o contrato e as mensagens em português já combinados.

Veja a mesma informação em outra apresentação

Acrescente os dicionários em lang/pt_BR e lang/en e aplique a view e o controller desta etapa. Abra http://localhost:8000/atendimento?idioma=en. Depois use o link “Português”. O número de minutos precisa permanecer o mesmo.

Internacionalização prepara o programa para diferentes idiomas e convenções. Localização fornece a apresentação de uma língua ou região. Em vez de colocar a frase pronta na view, usamos uma chave como atendimento.prazo e substituímos o valor variável quando apresentamos a mensagem.

Conferir lang/en/atendimento.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
return ['titulo'=>'Service','aberto'=>'Takeaway orders are open.','fechado'=>'Takeaway orders are closed.','semPrazo'=>'Ask our team about the collection time.','foraHorario'=>'Please check again during opening hours.','prazo'=>'Estimated time: :minutos minutes.'];

O marcador :minutos não é um novo campo do banco. É o lugar onde a tradução receberá o prazo que já conhecemos. Se os pedidos estão encerrados, a view escolhe a mensagem de encerramento antes de apresentar uma estimativa.

Conferir app/Http/Controllers/AtendimentoController.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
namespace App\Http\Controllers;
use App\Http\Requests\AtualizarAtendimentoRequest;
use App\Models\AtendimentoAtual;
use Illuminate\Http\JsonResponse;
use Illuminate\Http\RedirectResponse;
use Illuminate\Contracts\View\View;

class AtendimentoController
{
    public function mostrar(\Illuminate\Http\Request $pedido): View
    {
        $idioma=$pedido->query('idioma','pt_BR');
        abort_unless(in_array($idioma,['pt_BR','en'],true),400);
        app()->setLocale($idioma);
        return view('atendimento', ['atendimento' => AtendimentoAtual::findOrFail(1)]);
    }
    public function publico(): JsonResponse
    {
        return response()->json(AtendimentoAtual::findOrFail(1)->mensagens())->header('Cache-Control','no-store');
    }
    public function editar(): View
    {
        return view('editar-atendimento', ['atendimento' => AtendimentoAtual::findOrFail(1)]);
    }
    public function salvar(AtualizarAtendimentoRequest $pedido): RedirectResponse
    {
        AtendimentoAtual::findOrFail(1)->update($pedido->validated());
        return redirect()->route('operador.atendimento')->with('aviso', 'Aviso salvo; consulte o balcão para conferir.');
    }
}

O parâmetro idioma aceita apenas pt_BR ou en. Não usamos a entrada do visitante para montar livremente o nome de um arquivo. O layout também informa o idioma no atributo lang, importante para tecnologias assistivas e pronúncia.

Volte ao conjunto antes de concluir

Informe prazo vazio pela área da equipe e abra os dois idiomas. Depois encerre os pedidos e repita. Consulte o balcão: ele deve continuar funcionando com o contrato anterior, independentemente do último idioma aberto em outra aba.

Execute composer test. A suíte verifica a regra, a proteção da edição, o catálogo, respostas externas controladas e os idiomas trabalhados. Registre testes automatizados separadamente das verificações de celular, teclado, rede e extensões do seu computador.

Percorra também início, cardápio, mensagens do Web II e saída da área da equipe. Nossas alterações não autorizam perder uma funcionalidade anterior. Se um dado já salvo desapareceu, investigue a cópia do banco e os comandos usados; não tente reconstruí-lo inventando registros.

O Café está pronto para ser demonstrado?

Você deve conseguir explicar uma consulta completa: rota, controller, model, classe de regra, banco, view ou JSON. Demonstre uma edição autorizada, uma tentativa recusada e uma falha de serviço com recuperação. Escolha uma alteração pequena e mostre por que ela aparece em todos os consumidores previstos.
