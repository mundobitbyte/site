O botão consulta. Quem informa o aviso?

Café Aurora · cerca de 2 horas-aula de estudo, prática e verificação

Web III — Em desenvolvimento.

O botão do balcão já faz uma consulta de verdade. Ele pede o aviso ao PHP, espera a resposta e conta ao visitante quando não consegue confirmar a informação. Você não precisa reconstruir esse caminho.

Agora imagine Marina chegando à cozinha: “O movimento aumentou. A retirada passou para 47 minutos. Como eu atualizo isso sem abrir um arquivo de programação?” Até aqui, alguém precisava editar o PHP. O visitante ganhou autonomia para consultar; a equipe ainda precisa de autonomia para informar.

Antes de mudar, veja o que já funciona

Abra sua pasta final do Capítulo 2 no VS Code. Inicie o servidor PHP como você já fez: php -d opcache.enable=0 -S localhost:8000 -t public. No navegador, abra http://localhost:8000/balcao.php e use “Atualizar atendimento”. A resposta continua vindo de public/api/atendimento.php.

Se você estiver usando uma cópia nova do checkpoint, entre em cliente-balcao, execute npm ci e depois npm run build. Volte à raiz antes de iniciar o PHP. O download leva os arquivos-fonte; o build produz public/js/balcao/main.js. Live Preview continua útil para HTML estático, mas não executa o PHP desta aplicação.

Conseguiu consultar? Então siga. A revisão inteira do Web II não é uma condição para continuar. Se a consulta falhar, confira o endereço, o terminal do PHP e a última aula do Capítulo 2. O erro precisa ser resolvido onde apareceu, sem recomeçar o Café do zero.

Uma informação tem duas formas

Você já trabalhou com nomeNegocio, pedidosAbertos e tempoEstimado: nome, situação e minutos são os dados que a equipe informa. O serviço consultado pelo balcão devolve outras três propriedades: nomeNegocio, mensagemStatus e mensagemTempo. São mensagens prontas para mostrar.

Não vamos tentar extrair minutos de uma frase. Guardaremos 47 como número e prepararemos a mensagem quando ela for necessária. Esses 47 minutos são uma informação fictícia da equipe para nosso teste, não uma medição automática. null continuará significando “a equipe ainda não informou”; zero continuará sendo um valor informado.
