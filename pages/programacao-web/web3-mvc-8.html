Outro programa pede o mesmo aviso

Web III — Em desenvolvimento.

O Café vai participar de uma integração com um sistema mais antigo. Esse sistema consegue consultar o atendimento, mas sua interface foi definida com SOAP e XML. Reescrever o balcão para atender a ele seria inverter o problema: podemos oferecer outra forma de acesso à mesma informação.

Já expusemos uma API HTTP com JSON. Agora vamos comparar uma consulta equivalente definida por um contrato WSDL. A integração é uma bancada local de aprendizagem; não representa um fornecedor real contratado pelo Café.

Confira a extensão e separe os servidores

No terminal do Laragon ou do VS Code, execute php --ri soap. Se a extensão não estiver carregada, confira o php.ini indicado por php --ini, habilite a extensão SOAP da instalação e reinicie os servidores PHP. Não baixe DLLs de procedência desconhecida para resolver a mensagem.

Mantenha o Laravel na porta 8000. Em outro terminal, na raiz da aplicação, iniciaremos apenas o servidor SOAP na porta 9001. Separar as portas evita que o servidor embutido fique esperando uma chamada que precisaria atender a si mesmo.

php -d opcache.enable=0 -S 127.0.0.1:9001 apoio/soap/servidor.php

Deixe esse terminal em execução. Em um terceiro terminal, ainda na raiz, execute php apoio/soap/cliente.php. Deve aparecer o resultado da consulta e, abaixo, a requisição e a resposta em XML. O banco de atendimento precisa ter sido preparado nas etapas anteriores.

Leia primeiro o que estamos combinando

XML representa dados com elementos e atributos. SOAP define uma estrutura de mensagens, incluindo um envelope. WSDL descreve o serviço: operação, tipos envolvidos e endereço de acesso. Aqui a operação é consultar; ela oferece os mesmos três campos do atendimento.

Conferir contratos/atendimento.wsdl

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?xml version="1.0" encoding="UTF-8"?>
<definitions xmlns="http://schemas.xmlsoap.org/wsdl/" xmlns:soap="http://schemas.xmlsoap.org/wsdl/soap/" xmlns:xsd="http://www.w3.org/2001/XMLSchema" xmlns:tns="urn:CafeAurora" targetNamespace="urn:CafeAurora" name="Atendimento">
 <types><xsd:schema targetNamespace="urn:CafeAurora"><xsd:complexType name="Atendimento"><xsd:sequence><xsd:element name="nomeNegocio" type="xsd:string"/><xsd:element name="mensagemStatus" type="xsd:string"/><xsd:element name="mensagemTempo" type="xsd:string"/></xsd:sequence></xsd:complexType></xsd:schema></types>
 <message name="Consulta"/><message name="Resposta"><part name="return" type="tns:Atendimento"/></message>
 <portType name="AtendimentoPortType"><operation name="consultar"><input message="tns:Consulta"/><output message="tns:Resposta"/></operation></portType>
 <binding name="AtendimentoBinding" type="tns:AtendimentoPortType"><soap:binding style="rpc" transport="http://schemas.xmlsoap.org/soap/http"/><operation name="consultar"><soap:operation soapAction="urn:CafeAurora#consultar"/><input><soap:body use="literal" namespace="urn:CafeAurora"/></input><output><soap:body use="literal" namespace="urn:CafeAurora"/></output></operation></binding>
 <service name="AtendimentoService"><port name="AtendimentoPort" binding="tns:AtendimentoBinding"><soap:address location="http://127.0.0.1:9001/servidor.php"/></port></service>
</definitions>

Localize a operação e o endereço 127.0.0.1:9001 antes de estudar todos os elementos. Usamos o mesmo endereço no servidor e no contrato; localhost pode resolver para outro endereço local no computador. O cliente sabe que operação pedir e como interpretar sua resposta porque recebeu esse contrato.

Conferir apoio/soap/servidor.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
// Servidor didático local. A extensão soap precisa estar habilitada.
require_once dirname(__DIR__,2).'/src/atendimento.php';
class ServicoAtendimento { public function consultar(): array { return obterAtendimento(); } }
$servidor=new SoapServer(dirname(__DIR__,2).'/contratos/atendimento.wsdl',['cache_wsdl'=>WSDL_CACHE_NONE]);
$servidor->setClass(ServicoAtendimento::class);
$servidor->handle();
Conferir apoio/soap/cliente.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
// Execute pelo terminal, com o servidor separado na porta 9001.
$cliente=new SoapClient(dirname(__DIR__,2).'/contratos/atendimento.wsdl',['trace'=>true,'exceptions'=>true,'cache_wsdl'=>WSDL_CACHE_NONE,'connection_timeout'=>3,'stream_context'=>stream_context_create(['http'=>['timeout'=>5]])]);
try {
    $resposta=$cliente->consultar();
    echo json_encode($resposta,JSON_UNESCAPED_UNICODE|JSON_PRETTY_PRINT),PHP_EOL;
    echo "REQUISIÇÃO XML",PHP_EOL,$cliente->__getLastRequest(),PHP_EOL;
    echo "RESPOSTA XML",PHP_EOL,$cliente->__getLastResponse(),PHP_EOL;
} catch (SoapFault $erro) { fwrite(STDERR,"Falha SOAP: ".$erro->getMessage().PHP_EOL); exit(1); }

O servidor reaproveita obterAtendimento(). O cliente usa SoapClient, pede consultar() e permite examinar as mensagens trocadas. trace foi ativado para nossa observação local; não é uma orientação para registrar indiscriminadamente dados de clientes em produção.

Compare e provoque uma falha recuperável

Consulte também http://localhost:8000/api/atendimento. Compare os valores do JSON com os do XML. Mude o prazo pela tela autorizada, consulte novamente os dois consumidores e confirme que concordam.

Depois encerre apenas o servidor da porta 9001 e repita o cliente. Ele deve informar falha, sem inventar uma resposta. Reinicie o servidor e confira a recuperação. A falha SOAP não deve impedir a consulta JSON do balcão.

REST é um estilo arquitetural; JSON e XML são formatos; SOAP é um protocolo de mensagens; WSDL descreve um serviço. SOAP não exige, por si, manter estado entre consultas. Nesta operação, não precisamos abrir uma sessão para consultar o atendimento. Essa distinção evita transformar uma comparação curricular em uma regra técnica incorreta.

Dois contratos, uma origem

Identifique operação, endereço e campos no WSDL; mostre a requisição e a resposta XML; compare com o JSON; registre indisponibilidade e recuperação. Encerre o servidor extra quando terminar. Agora falta cuidar de outra forma de apresentação: mudar o idioma sem mudar os dados da cozinha.
