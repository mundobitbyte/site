O Café ganhou uma nova necessidade

O Café Aurora já recebe mensagens pelo site. Agora surgiu um pedido menor — e bastante concreto.

— Quero deixar uma tela no balcão para a equipe conferir se estamos recebendo pedidos para retirada e qual é o tempo estimado. Não precisa mostrar o site inteiro. Só o que ajuda naquele momento.

Vamos começar por essa tela. Você vai aproveitar o PHP e a apresentação do Café que já construiu, sem trocar de linguagem ou instalar um framework.

Abra uma cópia da sua entrega final do Web II. Use uma pasta de estudo separada para preservar a original. No terminal dessa cópia, inicie o servidor:

php -S localhost:8000 -t public

Abra http://localhost:8000/ e localize a mensagem de atendimento. Se a página abriu e você encontrou a informação, já podemos seguir.

Aqui você acompanha o material didático. O PHP será executado no seu computador; o site Mundo bit Byte não executa esses arquivos.

Minha cópia não abriu ou não tenho a entrega

Se o terminal não reconhece PHP, retome a preparação do Web II. Se a porta já estiver ocupada, encerre o servidor anterior com Ctrl + C ou escolha outra porta e use esse número no navegador.

O terminal deve estar na pasta que contém public. Abrir um arquivo PHP por duplo clique não executa o programa.

Se perdeu sua entrega, baixe a referência final do Web II, descompacte e trabalhe em uma cópia. Identifique que usou a referência; isso não substitui o estudo anterior. Para as duas primeiras páginas, ainda não é necessário preparar o banco.

Uma tela que já pode ajudar a equipe

Quem está no balcão não precisa procurar a estimativa entre todos os links do site. Vamos manter o nome do Café e a informação essencial.

Crie balcao.php dentro de public. Para a primeira versão, use o trecho conhecido do atendimento e uma página curta. O arquivo abaixo está completo; não substitui sua página inicial.

<?php
$nomeNegocio = "Café Aurora";
$pedidosAbertos = true;
$tempoEstimado = 25;

if ($pedidosAbertos) {
    $mensagemStatus = "Pedidos para retirada estão abertos.";
    $mensagemTempo = "Tempo estimado: $tempoEstimado minutos.";
} else {
    $mensagemStatus = "Pedidos para retirada estão encerrados.";
    $mensagemTempo = "Consulte novamente durante o horário de atendimento.";
}
?>
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Balcão — Café Aurora</title>
  <link rel="stylesheet" href="css/styles.css">
</head>
<body>
  <a class="skip-link" href="#conteudo">Pular para o conteúdo</a>
  <header>
    <p><a href="index.php">Café Aurora</a></p>
    <nav aria-label="Navegação do balcão">
      <ul><li><a href="index.php">Voltar ao site</a></li></ul>
    </nav>
  </header>
  <main id="conteudo" tabindex="-1">
    <h1><?= htmlspecialchars($nomeNegocio, ENT_QUOTES, "UTF-8") ?></h1>
    <section aria-labelledby="atendimento">
      <h2 id="atendimento">Atendimento no balcão</h2>
      <p><?= htmlspecialchars($mensagemStatus, ENT_QUOTES, "UTF-8") ?></p>
      <p><?= htmlspecialchars($mensagemTempo, ENT_QUOTES, "UTF-8") ?></p>
    </section>
  </main>
  <footer><p>Projeto educacional fictício — Café Aurora.</p></footer>
</body>
</html>

Salve e abra http://localhost:8000/balcao.php. O CSS já existe na sua cópia: o caminho css/styles.css reaproveita a apresentação do Café.

Se sua entrega já tinha outros valores, mantenha-os coerentes nas duas apresentações antes da experiência seguinte. O importante agora é reconhecer de onde cada página retira a informação.

Confira a leitura da nova tela. Ela já atende a uma necessidade do balcão. O uso de htmlspecialchars, conhecido do Web II, mantém os textos como texto no HTML; não é um novo sistema de segurança ou de pedidos.

Uma mudança pequena revela o problema

Imagine que o tempo de preparo aumentou. Na sua cópia de estudo, altere somente $tempoEstimado de balcao.php para 40. Antes de conferir, preveja: o site também mostrará 40?

Recarregue o site e o balcão. No exemplo de referência, o site continua com 25 minutos e o balcão mostra 40. As duas páginas estão respondendo, mas contam histórias diferentes.

O navegador não inventou um valor. Criamos duas fontes independentes: cada arquivo preparou sua própria informação. Se corrigirmos uma cópia e esquecermos a outra, a divergência volta.

Volte o balcão para 25 minutos depois da comparação. Não precisamos repetir o erro: ele já mostrou o limite da primeira tentativa.

Decidir uma vez, apresentar de formas diferentes

O site e o balcão podem ter apresentações diferentes. O estado do atendimento e a estimativa precisam concordar.

Copiar o texto novamente manteria o problema. Incluir a página inicial inteira também traria cabeçalho, cardápio e tudo o que o balcão não pediu. Vamos compartilhar apenas a preparação da informação.

Crie src/atendimento.php, ao lado dos arquivos de apoio do Web II. A função abaixo concentra os valores e a decisão que você já conhece:

<?php
function obterAtendimento(): array
{
    $nomeNegocio = "Café Aurora";
    $pedidosAbertos = true;
    $tempoEstimado = 25;

    if ($pedidosAbertos) {
        $mensagemStatus = "Pedidos para retirada estão abertos.";
        $mensagemTempo = "Tempo estimado: $tempoEstimado minutos.";
    } else {
        $mensagemStatus = "Pedidos para retirada estão encerrados.";
        $mensagemTempo = "Consulte novamente durante o horário de atendimento.";
    }

    return [
        "nomeNegocio" => $nomeNegocio,
        "mensagemStatus" => $mensagemStatus,
        "mensagemTempo" => $mensagemTempo
    ];
}

obterAtendimento() é o nome que usaremos para pedir essa informação. O : array declara o tipo do retorno. O return entrega um array com três campos nomeados; cada nome à esquerda de => identifica um texto preparado à direita.

Assim, quem apresenta não precisa repetir a decisão. Recebe nomeNegocio, mensagemStatus e mensagemTempo. Quando o atendimento está encerrado, a função devolve uma orientação para consultar novamente, sem oferecer um prazo de atendimento aberto.

O arquivo fica em src, fora da pasta pública. O PHP o acessa pelo sistema de arquivos; o visitante recebe somente o resultado das páginas públicas.

O balcão passa a consultar a fonte

Substitua o conteúdo de public/balcao.php pela versão abaixo. Observe o que mudou antes de copiar: saíram os valores e o if locais; entraram a inclusão e a chamada da função. Os três textos agora vêm do array recebido.

<?php
require_once dirname(__DIR__) . "/src/atendimento.php";
$atendimento = obterAtendimento();
?>
<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Balcão — Café Aurora</title>
  <link rel="stylesheet" href="css/styles.css">
</head>
<body>
  <a class="skip-link" href="#conteudo">Pular para o conteúdo</a>
  <header>
    <p><a href="index.php">Café Aurora</a></p>
    <nav aria-label="Navegação do balcão">
      <ul><li><a href="index.php">Voltar ao site</a></li></ul>
    </nav>
  </header>
  <main id="conteudo" tabindex="-1">
    <h1><?= htmlspecialchars($atendimento["nomeNegocio"], ENT_QUOTES, "UTF-8") ?></h1>
    <section aria-labelledby="atendimento">
      <h2 id="atendimento">Atendimento no balcão</h2>
      <p><?= htmlspecialchars($atendimento["mensagemStatus"], ENT_QUOTES, "UTF-8") ?></p>
      <p><?= htmlspecialchars($atendimento["mensagemTempo"], ENT_QUOTES, "UTF-8") ?></p>
    </section>
  </main>
  <footer><p>Projeto educacional fictício — Café Aurora.</p></footer>
</body>
</html>

__DIR__ indica a pasta de balcao.php. dirname(__DIR__) sobe para a raiz da cópia; a continuação aponta para src/atendimento.php. O require_once carrega o arquivo uma vez naquela requisição. Depois, a chamada da função prepara o array usado no HTML.

Salve e confira a sintaxe antes de abrir a página:

php -l src/atendimento.php
php -l public/balcao.php

O terminal deve informar ausência de erros de sintaxe. Recarregue o balcão: ele continua mostrando os mesmos textos. A organização mudou; a informação foi preservada.

Apareceu “Failed opening required” ou “Call to undefined function”

Confira os nomes das pastas e arquivos, inclusive maiúsculas e minúsculas. A função precisa ter o mesmo nome na declaração e na chamada. O arquivo de apoio deve ficar em src, não dentro de public. Corrija, rode php -l e solicite a página novamente.

Antes de ligar a segunda apresentação

Você já criou uma tela útil e fez o balcão consultar uma fonte identificada. A página inicial ainda mantém a decisão anterior: vamos conectá-la na próxima aula.

  • Mostre o balcão funcionando.
  • Localize o arquivo que agora prepara seus textos.
  • Explique por que manter duas decisões independentes causou divergência.
