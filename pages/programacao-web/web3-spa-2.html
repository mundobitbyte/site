Web III · Interface com React

Abrir uma orientação muda o estado

Café Aurora · cerca de 4 horas-aula de estudo, prática e verificação

Web III — Em desenvolvimento.

A orientação de retirada aparece, mas ocupa espaço mesmo quando a pessoa só quer consultar o atendimento. Marina propõe um botão: quem precisar pode abrir a explicação e fechá-la depois.

O pedido é pequeno e sua primeira solução também será. Não precisamos consultar o servidor, criar uma conta ou instalar outra biblioteca para mudar a apresentação de uma orientação.

Uma pergunta com duas respostas

Vamos representar “a orientação está aberta?” com um booleano. Em React, uma informação que pode mudar e provocar uma nova apresentação é um estado. useState(false) cria esse estado começando fechado.

Conferir cliente-balcao/src/App.tsx

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import {useState} from "react";
export function App(){
 const [mostrar,setMostrar]=useState(false);
 return <><h1>Café Aurora · Balcão</h1><button type="button" aria-expanded={mostrar} aria-controls="orientacao" onClick={()=>setMostrar(!mostrar)}>Como consultar?</button><div id="orientacao" hidden={!mostrar}><p>O prazo pode mudar. Abrir esta orientação só muda a apresentação; atualizar a consulta pede o aviso atual à cozinha.</p></div></>;
}

A desestruturação entrega dois valores: mostrar contém o estado atual; setMostrar solicita sua atualização. Não alteramos mostrar diretamente, pois React precisa acompanhar a mudança para atualizar a interface.

O botão recebe uma função em onClick. Ela só será chamada quando houver o evento; não escrevemos uma chamada que execute a mudança durante a montagem da tela. !mostrar inverte verdadeiro e falso.

Veja a mudança antes de acrescentar outra

Substitua o conteúdo de App.tsx, faça npm run build em cliente-balcao e recarregue o balcão pelo PHP. Use o botão três vezes. A orientação precisa abrir, fechar e abrir novamente sem recarregar o documento inteiro.

Observe hidden={!mostrar}: a apresentação acompanha o estado. Em aria-expanded, informamos a mesma condição a tecnologias assistivas. aria-controls liga o botão ao identificador da orientação. A informação visual e a informação acessível precisam concordar.

Agora recarregue a página. O estado volta ao valor inicial. Esse é um estado em memória, não um dado salvo no banco. Abrir uma explicação também não atualiza o prazo de retirada. Esse contraste será útil na próxima aula: consultar um serviço é uma ação diferente de abrir uma ajuda.

Consegue prever a próxima apresentação?

Antes de cada clique, diga qual valor mostrar terá e se o conteúdo ficará visível. Confira o botão com Tab e Enter. Explique por que não precisamos buscar o elemento pelo DOM e alterar seu texto manualmente. Com essa interação compreendida, podemos recolocar a consulta real do atendimento dentro de um componente.
