Web III · Interface com React

Uma área do balcão ganha componentes

Web III — Em desenvolvimento.

O balcão já consulta o aviso sem recarregar a página. Marina quer acrescentar uma orientação de retirada e, depois, permitir consultas ao cardápio na mesma área. Se continuarmos distribuindo mudanças de texto e visibilidade pelo arquivo inteiro, ficará difícil saber qual parte da interface cada função controla.

Vamos experimentar React em uma área delimitada: o balcão. A página inicial, o cardápio anterior e o sistema de mensagens continuam existindo. Você não vai converter o Café inteiro nem precisa ter concluído o módulo de React Native.

Preparar os arquivos desta etapa

Baixar a referência da etapa 1. Ela contém a aplicação ao final desta etapa; não é uma nova tarefa nem uma substituição automática da sua solução.

Continue na sua pasta de trabalho que concluiu a entrega do Capítulo 2. A raiz é o lugar onde aparecem public e cliente-balcao. Não crie uma pasta cafe-aurora-web3 dentro dessa raiz.

  1. Salve os arquivos e pare o servidor antes de copiar dados. Preserve uma cópia da pasta atual.
  2. Extraia o download em uma pasta de referência separada. Abra o LEIA-ME-ETAPA.md que está dentro de cafe-aurora-web3.
  3. Compare os caminhos listados abaixo com sua pasta de trabalho. Acrescente os arquivos de apoio que ainda não existem. Para um arquivo já existente, compare a alteração antes de aplicá-la: não apague uma mudança sua sem entender a diferença. Os arquivos discutidos na aula são os que vamos construir e compreender.

Preserve dados, credenciais locais, .env e as dependências já instaladas. Uma pasta ausente no ZIP não é uma instrução para apagar sua cópia. A aula informa quando executar Composer, npm, migration ou build; copiar arquivos não executa esses preparos.

Faça uma orientação aparecer

Preserve sua pasta final do Capítulo 2. Acrescente os arquivos de apoio do download e compare public/balcao.php: o lugar que React controlará é <div id="cafe-app">. O restante da página continua sendo HTML/PHP.

React é uma biblioteca para construir interfaces por componentes. Um componente descreve uma parte da apresentação. Nesta primeira experiência ele recebe um título e um texto e devolve a orientação que veremos no navegador.

Conferir cliente-balcao/src/App.tsx

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

interface OrientacaoProps { titulo: string; texto: string }
function Orientacao({titulo,texto}:OrientacaoProps){return <section><h2>{titulo}</h2><p>{texto}</p></section>;}
export function App(){return <><h1>Café Aurora · Balcão</h1><Orientacao titulo="Antes de retirar" texto="Consulte o atendimento para confirmar a abertura dos pedidos e o prazo informado pela equipe."/></>;}

OrientacaoProps é uma interface TypeScript para os valores recebidos, chamados props. A função Orientacao usa esses valores. A sintaxe parecida com HTML se chama JSX; com TypeScript, o arquivo recebe extensão .tsx. É sintaxe processada pelo build, não HTML colocado dentro de uma string.

Troque apenas o texto da orientação por uma frase útil para a retirada. Antes de acrescentar outra funcionalidade, vamos ver essa pequena mudança funcionando.

O editor continua sendo o VS Code

Você escreve TSX no VS Code. npm instala as dependências; Vite transforma os arquivos-fonte em JavaScript para o navegador. São papéis diferentes. Continue com Node 24, já preparado no TypeScript Essencial, e execute em cliente-balcao:

npm ci
npm run build

Na raiz, inicie php -d opcache.enable=0 -S localhost:8000 -t public e abra http://localhost:8000/balcao.php. O texto precisa aparecer dentro do balcão. Alterou TSX? Novo build e recarregamento. Não estamos usando Live Preview para executar PHP nem o servidor de desenvolvimento do Vite para substituir o servidor PHP.

Conferir cliente-balcao/src/main.tsx

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import { createRoot } from "react-dom/client";
import { App } from "./App.js";

const raiz = document.querySelector("#cafe-app");
if (!(raiz instanceof HTMLElement)) throw new Error("Confira a área cafe-app em balcao.php.");
createRoot(raiz).render(<App />);

Na função Orientacao, {titulo,texto} retira duas propriedades do objeto recebido. É uma desestruturação: poderíamos receber props e ler props.titulo e props.texto. export disponibiliza App para o arquivo que a importa.

createRoot liga React ao elemento cafe-app e render apresenta App. O antigo main.ts foi preservado como referência em main-anterior.ts.txt. Ele não deve continuar controlando os elementos que React passará a renderizar. Preserve sua versão anterior com esse nome e retire src/main.ts; o novo arquivo de entrada é src/main.tsx. Os imports que terminam em .js são resolvidos pelo TypeScript/Vite a partir dos fontes: não crie cópias JavaScript à mão.

Uma parte mudou; o projeto continua

Mostre sua orientação, explique de onde vêm título e texto e confira início e cardápio pelos links anteriores. Esta primeira tela React ainda não consulta o aviso; a API continua existindo e voltará à interface depois que aprendermos a mudar uma pequena parte da apresentação por interação.
