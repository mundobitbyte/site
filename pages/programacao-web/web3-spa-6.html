Web III · Interface com React

O balcão ganha caminhos

Web III — Em desenvolvimento.

Atendimento e cardápio já funcionam no balcão. Mantê-los sempre abertos, porém, ocupa espaço e torna difícil compartilhar um endereço que leve à área desejada. Vamos organizar a navegação sem exigir outra página PHP para cada apresentação.

Uma SPA, aplicação de página única, pode alternar áreas dentro do mesmo documento. Isso não significa que o servidor deixou de existir ou que tudo funciona sem rede: continuamos consultando os serviços PHP.

Um endereço para cada área

Usaremos o trecho depois de #, chamado fragmento ou hash. balcao.php#atendimento e balcao.php#cardapio abrem o mesmo documento e indicam qual apresentação mostrar. O navegador mantém seu histórico, e o servidor continua recebendo balcao.php.

Conferir cliente-balcao/src/App.tsx

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import { useEffect, useRef, useState } from "react";
import { obterAtendimento } from "./atendimento.js";
import type { Atendimento as Dados } from "./atendimento.js";
import { Atendimento } from "./componentes/Atendimento.js";
import { Cardapio } from "./componentes/Cardapio.js";

import { lerProdutos } from "./servicos/api.js";
import type { Produto } from "./servicos/api.js";

const rotas = ["atendimento", "cardapio"];
function rotaAtual(): string {
  const hash = location.hash.slice(1);
  return rotas.includes(hash) ? hash : "atendimento";
}

export function App() {
  const [rota, setRota] = useState(rotaAtual);
  const [dados, setDados] = useState<Dados | null>(null);
  const [consultando, setConsultando] = useState(false);
  const [aviso, setAviso] = useState("Consulte o atendimento para receber o aviso atual.");
  const [produtos, setProdutos] = useState<Produto[]>([]);
  const [avisoProdutos, setAvisoProdutos] = useState("");
  const [busca, setBusca] = useState("");
  const [categoria, setCategoria] = useState("todas");
  const consultaAtiva = useRef(false);
  const ordemProdutos = useRef(0);

  async function consultar() {
    if (consultaAtiva.current) return;
    const foco = document.activeElement;
    consultaAtiva.current = true; setConsultando(true); setDados(null); setAviso("Consultando o atendimento…");
    try { setDados(await obterAtendimento()); setAviso("Atendimento consultado agora."); }
    catch { setAviso("Não foi possível consultar. Tente novamente."); }
    finally {
      consultaAtiva.current = false; setConsultando(false);
      requestAnimationFrame(() => { if (foco instanceof HTMLButtonElement && document.activeElement === document.body) foco.focus({ preventScroll: true }); });
    }
  }

  async function carregarProdutos(preservar = false) {
    const ordem = ++ordemProdutos.current;
    if (!preservar) setProdutos([]);
    setAvisoProdutos("Consultando o cardápio…");
    try {
      const recebidos = await lerProdutos();
      if (ordem === ordemProdutos.current) { setProdutos(recebidos); setAvisoProdutos(""); }
    } catch { if (ordem === ordemProdutos.current) setAvisoProdutos("Não foi possível consultar o cardápio. Tente novamente."); }
  }

  useEffect(() => {
    function mudar() { setRota(rotaAtual()); }
    window.addEventListener("hashchange", mudar);
    return () => window.removeEventListener("hashchange", mudar);
  }, []);
  useEffect(() => {
    document.getElementById("titulo-rota")?.focus({ preventScroll: true });
    if (rota !== "atendimento") void carregarProdutos();
  }, [rota]);

  return <>
    <h1 id="titulo-rota" tabIndex={-1}>Café Aurora · {rota === "cardapio" ? "Cardápio" : rota === "operador" ? "Operador" : "Balcão"}</h1>
    <nav aria-label="Áreas do Café"><a href="#atendimento" aria-current={rota === "atendimento" ? "page" : undefined}>Atendimento</a>{" · "}<a href="#cardapio" aria-current={rota === "cardapio" ? "page" : undefined}>Cardápio</a></nav>
    {rota === "atendimento" && <Atendimento dados={dados} consultando={consultando} aviso={aviso} aoConsultar={() => void consultar()} />}
    {rota === "cardapio" && <><button onClick={() => void carregarProdutos()}>Consultar cardápio</button><p role="status">{avisoProdutos}</p><Cardapio produtos={produtos} busca={busca} categoria={categoria} aoBuscar={setBusca} aoCategorizar={setCategoria} /></>}
  </>;
}

rotaAtual aceita os nomes que definimos e volta ao atendimento se o fragmento não corresponder a uma área. O estado rota acompanha essa escolha. A interface monta o componente correspondente sem duplicar a origem dos dados.

Reaja à navegação e limpe o que instalou

useEffect permite sincronizar a interface com algo externo à apresentação, como o evento hashchange do navegador. O efeito registra a função de atualização e devolve uma função para remover o ouvinte quando ele não for mais necessário. Assim não acumulamos vários ouvintes para a mesma ação.

Outro efeito atualiza o foco do título e consulta o catálogo quando entramos na área que precisa dele. O título focável e aria-current ajudam a perceber qual área foi aberta, inclusive sem depender apenas da cor do link.

Não estamos instalando um roteador adicional nesta etapa. Para essas poucas áreas, o fragmento deixa o comportamento observável e mantém os endereços compatíveis com o servidor PHP já preparado.

Experimente o histórico de verdade

Faça o build. Abra o atendimento, siga para o cardápio e use Voltar e Avançar do navegador. Depois cole http://localhost:8000/balcao.php#cardapio em outra aba. A área correta deve abrir também nesse acesso direto.

O arquivo public/cardapio.php desta etapa redireciona para a área React. Assim o menu da página inicial continua levando ao cardápio atual quando começarmos a editar descrições. Não manteremos uma apresentação antiga como se fosse a fonte atualizada.

A pessoa sabe onde está e consegue voltar?

Confira links, endereço direto, histórico, indicação da área atual e foco do título. Um fragmento desconhecido deve voltar ao atendimento de forma previsível. A próxima área será reservada à equipe; mudar o hash não poderá dar permissão de edição a um visitante.
