Uma operação no ambiente confiável

Web III — Em desenvolvimento.

Marina alterou o atendimento e quer consultar um registro das mudanças. A própria página poderia tentar escrever esse histórico, mas um cliente diferente poderia omitir o passo. A operação precisa acontecer em um ambiente que o visitante não controla.

Functions permite executar código de servidor em resposta a chamadas e eventos. “Serverless” descreve uma forma de execução gerenciada; servidores continuam existindo. Vamos exercitar esse desenho no emulador, sem implantar funções em nuvem.

Uma chamada que confere identidade e entrada

Entre como operador no balcão, preencha uma estimativa diferente e use “Salvar por função”. A chamada inclui a identidade; a função confere a claim e valida os dados novamente. O SDK Admin usado dentro da função tem privilégios e não depende das regras de cliente, por isso essa validação não pode ser omitida.

Conferir functions/src/index.ts

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import { initializeApp } from "firebase-admin/app";
import { getFirestore, FieldValue } from "firebase-admin/firestore";
import { getMessaging } from "firebase-admin/messaging";
import { onCall, HttpsError, type CallableRequest } from "firebase-functions/v2/https";
import { onDocumentUpdated } from "firebase-functions/v2/firestore";
import { createHash } from "node:crypto";
import { conferir, mudou, conferirPedido, conferirRascunho } from "./regras";

initializeApp();
const banco = getFirestore();
const limites = { region: "us-central1", maxInstances: 1, concurrency: 10, timeoutSeconds: 20 };
function operador(p: CallableRequest<unknown>): string {
  if (!p.auth) throw new HttpsError("unauthenticated", "Entre no Café.");
  if (p.auth.token.operador !== true) throw new HttpsError("permission-denied", "Esta ação é do operador.");
  return p.auth.uid;
}
export const alterarAtendimentoSeguro = onCall(limites, async p => {
  operador(p);
  let dados;
  try { dados = conferir(p.data); }
  catch { throw new HttpsError("invalid-argument", "Confira os dados do atendimento."); }
  await banco.doc("atendimento/atual").set(dados);
  return { confirmado: true };
});

export const registrarMudanca = onDocumentUpdated({ ...limites, document: "atendimento/atual" }, async evento => {
  if (!evento.data) return;
  let antes, depois;
  try { antes = conferir(evento.data.before.data()); depois = conferir(evento.data.after.data()); }
  catch { console.warn("Evento com configuração inválida foi ignorado."); return; }
  if (!mudou(antes, depois)) return;
  // Mesmo evento pode chegar novamente. O identificador determinístico evita outra gravação.
  const id = createHash("sha256").update(evento.id).digest("hex");
  try { await banco.doc(`historico/${id}`).create({ eventoId: evento.id, antes, depois, registradoEm: FieldValue.serverTimestamp() }); }
  catch (erro) { if (!(typeof erro === "object" && erro !== null && "code" in erro && erro.code === 6)) throw erro; }
});

  const retorno=elemento("#retorno-funcao");
  try {
    const minutos=elemento<HTMLInputElement>("#minutos").value;
    const dados=conferirConfiguracao({nomeNegocio:elemento<HTMLInputElement>("#nome").value,pedidosAbertos:elemento<HTMLSelectElement>("#aberto").value==='1',tempoEstimado:minutos.trim()===''?null:Number(minutos)});
    await httpsCallable(funcoes,"alterarAtendimentoSeguro")(dados);
    retorno.textContent="Função confirmou a alteração. Confira a consulta e o histórico do emulador.";
  } catch { retorno.textContent="A função não confirmou a alteração. Confira identidade, dados e logs."; }
});

onCall define uma operação chamável. onDocumentUpdated acompanha alterações no documento. No emulador, localize historico depois de mudar um valor de verdade. O registro relaciona antes e depois.

Um evento pode ser recebido mais de uma vez

Um sistema distribuído pode reenviar eventos. Criar sempre um registro com identificador aleatório duplicaria o histórico. Nosso exemplo deriva o identificador do evento e usa uma criação que recusa duplicata. Repetir a entrega do mesmo evento não deve criar outro registro.

Também comparamos antes e depois. Salvar os mesmos valores não deve produzir uma mudança fictícia. O histórico contém somente dados de exercício e não é apresentado como auditoria completa de uma aplicação de produção.

Conferir functions/src/regras.ts

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

export interface Configuracao { nomeNegocio: string; pedidosAbertos: boolean; tempoEstimado: number | null }
export function conferir(d: unknown): Configuracao {
  if (typeof d !== "object" || d === null || Array.isArray(d)) throw new Error("Configuração inválida.");
  const p = d as Record<string, unknown>;
  if (Object.keys(p).length !== 3 || typeof p.nomeNegocio !== "string" || p.nomeNegocio.trim() === "" || p.nomeNegocio.length > 100 ||
      typeof p.pedidosAbertos !== "boolean" || !(p.tempoEstimado === null || typeof p.tempoEstimado === "number" && Number.isInteger(p.tempoEstimado) && p.tempoEstimado >= 0 && p.tempoEstimado <= 240)) throw new Error("Confira nome, situação e prazo.");
  return { nomeNegocio: p.nomeNegocio.trim(), pedidosAbertos: p.pedidosAbertos, tempoEstimado: p.tempoEstimado };
}
export function mudou(a: Configuracao, b: Configuracao): boolean {
  return a.nomeNegocio !== b.nomeNegocio || a.pedidosAbertos !== b.pedidosAbertos || a.tempoEstimado !== b.tempoEstimado;
}
export function conferirPedido(d: unknown): { produto: string; ingredientes: string } {
  if (typeof d !== "object" || d === null || !("produto" in d) || !("ingredientes" in d) || typeof d.produto !== "string" || typeof d.ingredientes !== "string" ||
      d.produto.trim().length < 2 || d.produto.length > 100 || d.ingredientes.length < 3 || d.ingredientes.length > 300) throw new Error("Informe produto e ingredientes conhecidos, sem dados pessoais.");
  return { produto: d.produto.trim(), ingredientes: d.ingredientes.trim() };
}
export function conferirRascunho(texto: unknown): string {
  if (typeof texto !== "string" || texto.trim().length < 10 || texto.length > 400) throw new Error("Rascunho fora dos limites. Revise a resposta do serviço.");
  return texto.trim();
}

Quem pode chamar e o que aconteceu depois?

Mostre chamada autorizada, recusa sem permissão, entrada inválida e histórico de uma alteração real. Registre separadamente a confirmação da função e a observação do evento. Agora podemos discutir avisos fora da página, sem confundir atualização em tempo real com notificação push.
