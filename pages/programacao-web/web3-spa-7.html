Web III · Interface com React

Entrar não basta para alterar

Web III — Em desenvolvimento.

Marina precisa entrar para alterar as informações. Podemos acrescentar “Operador” ao menu, mas esse nome sozinho não protege nada: qualquer pessoa consegue escrever #operador no endereço.

A interface pode orientar o acesso. Quem decide se uma operação é permitida continua sendo o servidor. Vamos primeiro confirmar entrada e saída, antes de colocar o formulário de alteração na tela.

Prepare uma identidade local

Se já criou o administrador local no Web II, preserve esse arquivo e utilize a identidade de exercício que escolheu. Em uma cópia nova, execute php src/criar-administrador.php na raiz e responda às perguntas do terminal. Esse acesso pertence à aplicação do Café, não ao Meu MbB. Não use credenciais pessoais.

Abra http://localhost:8000/api/sessao.php em uma janela sem login. O servidor informa se há uma sessão autenticada e fornece um token CSRF. O token não é uma senha nem um comprovante de identidade: ele ajuda a verificar a origem do envio associado à sessão.

Consulte a sessão e apresente a entrada

import { useEffect, useState } from "react";
import type { Configuracao, Produto, Sessao } from "../servicos/api.js";
import { gravarConfiguracao, lerConfiguracao, mudarSessao } from "../servicos/api.js";


interface Props { sessao: Sessao; aoMudarSessao: (s: Sessao) => void; produtos: Produto[]; aoRecarregarProdutos: (preservar?: boolean) => Promise<void> }

export function Operador({ sessao, aoMudarSessao, produtos, aoRecarregarProdutos }: Props) {
  const [usuario, setUsuario] = useState("");
  const [senha, setSenha] = useState("");
  const [config, setConfig] = useState<Configuracao | null>(null);
  const [prazo, setPrazo] = useState("");
  const [aviso, setAviso] = useState("");
  const [ocupado, setOcupado] = useState(false);
  useEffect(() => {
    let ativo = true;
    if (!sessao.autenticado) { setConfig(null); return; }
    void lerConfiguracao().then(d => {
      if (ativo) { setConfig(d); setPrazo(d.tempoEstimado === null ? "" : String(d.tempoEstimado)); }
    }).catch(() => { if (ativo) setAviso("Não foi possível consultar a configuração. Atualize sua sessão."); });
    return () => { ativo = false; };
  }, [sessao.autenticado]);

  async function entrar(evento: React.FormEvent) {
    evento.preventDefault(); setOcupado(true);
    try {
      const atual = await mudarSessao(sessao, { acao: "entrar", usuario, senha });
      setSenha(""); aoMudarSessao(atual); setAviso("Sessão confirmada pelo servidor.");
      await aoRecarregarProdutos();
    } catch (e) { setAviso(e instanceof Error ? e.message : "Falha no acesso."); }
    finally { setOcupado(false); }
  }
  async function salvar(evento: React.FormEvent) {
    evento.preventDefault(); if (!config) return; setOcupado(true);
    try {
      if (prazo !== "" && !/^(0|[1-9][0-9]{0,2})$/.test(prazo)) throw new Error("Informe minutos inteiros ou deixe vazio.");
      const minutos = prazo === "" ? null : Number(prazo);
      if (minutos !== null && minutos > 240) throw new Error("O limite combinado neste formulário é 240 minutos.");
      await gravarConfiguracao(sessao, { ...config, tempoEstimado: minutos });
      setAviso("Aviso salvo no servidor. Consulte o balcão para conferir.");
    } catch (e) { setAviso(e instanceof Error ? e.message : "Não foi possível salvar."); }
    finally { setOcupado(false); }
  }
  async function sair() {
    setOcupado(true);
    try {
      aoMudarSessao(await mudarSessao(sessao, { acao: "sair" }));
      setConfig(null); setAviso("Você saiu da área de edição.");
      await aoRecarregarProdutos();
    } catch { setAviso("Não foi possível sair. Tente novamente."); }
    finally { setOcupado(false); }
  }
  return <section><h2>Área do operador</h2>
    {!sessao.autenticado ? <form onSubmit={e => void entrar(e)}>
      <p><label htmlFor="usuario">Usuário local</label><input id="usuario" value={usuario} autoComplete="username" required onChange={e => setUsuario(e.target.value)} /></p>
      <p><label htmlFor="senha">Senha</label><input id="senha" type="password" value={senha} autoComplete="current-password" required onChange={e => setSenha(e.target.value)} /></p>
      <button disabled={ocupado || !sessao.csrfToken}>Entrar</button>
    </form> : <>
      <button disabled={ocupado} onClick={() => void sair()}>Sair da edição</button>

    </>}
    <p role="status">{aviso}</p>
  </section>;
}

O estado recebido em sessao orienta a apresentação. Sem autenticação, mostramos o formulário. Ao entrar, enviamos a tentativa para o PHP e consultamos novamente a sessão confirmada pelo servidor. A senha é retirada do estado depois da entrada; não é salva em localStorage.

Em servicos/api.ts, acompanhe agora consultarSessao, mudarSessao e pedir. credentials: "same-origin" mantém a sessão para a própria origem. A escrita envia JSON e o token no cabeçalho X-CSRF-Token.

export interface Produto {
  id: string;
  nome: string;
  categoria: string;
  precoCentavos: number;
  imagem: string;
  alt: string;
  descricao: string;
  disponivel: boolean;
  rascunho?: string | null;
}
export interface Sessao { autenticado: boolean; csrfToken: string }
export interface Configuracao { nomeNegocio: string; pedidosAbertos: boolean; tempoEstimado: number | null }

function objeto(v: unknown): v is Record<string, unknown> {
  return typeof v === "object" && v !== null && !Array.isArray(v);
}

export async function pedir(caminho: string, opcoes: RequestInit = {}): Promise<unknown> {
  const controlador = new AbortController();
  const limite = setTimeout(() => controlador.abort(), 8000);
  try {
    const resposta = await fetch(caminho, { ...opcoes, credentials: "same-origin", cache: "no-store", signal: controlador.signal });
    const tipo = resposta.headers.get("Content-Type");
    if (tipo === null || tipo.split(";")[0].trim().toLowerCase() !== "application/json") throw new Error("O serviço não devolveu JSON.");
    const dados: unknown = await resposta.json();
    if (!resposta.ok) throw new Error(objeto(dados) && typeof dados.erro === "string" ? dados.erro : `Falha HTTP ${resposta.status}.`);
    return dados;
  } finally { clearTimeout(limite); }
}

export async function consultarSessao(): Promise<Sessao> {
  const d = await pedir("api/sessao.php");
  if (!objeto(d) || typeof d.autenticado !== "boolean" || typeof d.csrfToken !== "string") throw new Error("Resposta de sessão inválida.");
  return { autenticado: d.autenticado, csrfToken: d.csrfToken };
}

export async function mudarSessao(sessao: Sessao, dados: { acao: "entrar" | "sair"; usuario?: string; senha?: string }): Promise<Sessao> {
  await pedir("api/sessao.php", { method: "POST", headers: { "Content-Type": "application/json", "X-CSRF-Token": sessao.csrfToken }, body: JSON.stringify(dados) });
  return consultarSessao();
}

export async function lerProdutos(): Promise<Produto[]> {
  const d = await pedir("api/cardapio.php");
  if (!objeto(d) || !Array.isArray(d.produtos)) throw new Error("Lista de produtos inválida.");
  return d.produtos.map((p: unknown) => {
    if (!objeto(p) || typeof p.id !== "string" || typeof p.nome !== "string" || typeof p.categoria !== "string" || typeof p.imagem !== "string" || typeof p.alt !== "string" || typeof p.descricao !== "string" ||
        typeof p.precoCentavos !== "number" || !Number.isSafeInteger(p.precoCentavos) || p.precoCentavos < 0 || typeof p.disponivel !== "boolean") throw new Error("Produto inválido.");
    if (typeof p.imagem !== "string" || !/^[a-zA-Z0-9_-]+\.webp$/.test(p.imagem)) throw new Error("Imagem de produto inválida.");
    if (!(p.rascunho === undefined || p.rascunho === null || typeof p.rascunho === "string")) throw new Error("Rascunho inválido.");
    return { id: p.id, nome: p.nome, categoria: p.categoria, precoCentavos: p.precoCentavos,
      imagem: p.imagem, alt: p.alt, descricao: p.descricao, disponivel: p.disponivel, rascunho: p.rascunho };
  });
}

export async function gravarProduto(sessao: Sessao, id: string, descricao: string, acao: "rascunho" | "publicar"): Promise<void> {
  await pedir("api/cardapio.php", { method: "POST", headers: { "Content-Type": "application/json", "X-CSRF-Token": sessao.csrfToken }, body: JSON.stringify({ id, descricao, acao }) });
}

export async function lerConfiguracao(): Promise<Configuracao> {
  const d = await pedir("api/configuracao-atendimento.php");
  const a = objeto(d) ? d.atendimento : null;
  if (!objeto(a) || typeof a.nomeNegocio !== "string" || typeof a.pedidosAbertos !== "boolean" ||
      !(a.tempoEstimado === null || typeof a.tempoEstimado === "number" && Number.isInteger(a.tempoEstimado))) throw new Error("Configuração inválida.");
  return { nomeNegocio: a.nomeNegocio, pedidosAbertos: a.pedidosAbertos, tempoEstimado: a.tempoEstimado };
}

export async function gravarConfiguracao(sessao: Sessao, atendimento: Configuracao): Promise<void> {
  await pedir("api/configuracao-atendimento.php", { method: "POST", headers: { "Content-Type": "application/json", "X-CSRF-Token": sessao.csrfToken }, body: JSON.stringify(atendimento) });
}

Fazer uma pergunta ao servidor e conferir a resposta é mais confiável que manter um booleano decidido pelo próprio navegador. Mesmo com a tela aberta, uma sessão pode ter expirado; o serviço precisa poder recusar a próxima ação.

Entre, saia e tente novamente

Faça o build e abra a área Operador. Tente uma senha incorreta: a mensagem deve orientar sem abrir a edição. Depois entre com os dados locais corretos e use “Sair da edição”. Volte pelo histórico e confirme que a apresentação acompanha a condição atual.

O serviço api/configuracao-atendimento.php já exige autenticação para ler a configuração privada e valida sessão/token para gravar. A consulta pública de mensagens continua acessível ao visitante. Não precisamos divulgar campos privados para mostrar o aviso do balcão.

Abrir uma área não concede acesso

Mostre tentativa recusada, entrada confirmada, saída e consulta pública ainda funcionando. Não salve senhas nos arquivos entregues. Com a identidade estabelecida, poderemos acrescentar a edição do aviso sem confundir o que a equipe informa com as mensagens que o visitante recebe.
