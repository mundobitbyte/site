O balcão acompanha a mudança

Web III — Em desenvolvimento.

Marina alterou o prazo, mas a pessoa no balcão não apertou Atualizar. Se a página precisa acompanhar o atendimento durante algum tempo, podemos assinar as mudanças em vez de repetir consultas sem parar.

Uma assinatura mantém uma escuta ativa. Ela precisa ter início, tratamento de falha e encerramento. Não é uma garantia de que o navegador estará sempre conectado.

Preparar os arquivos desta etapa

Baixar a referência da etapa 5. Ela contém a aplicação ao final desta etapa; não é uma nova tarefa nem uma substituição automática da sua solução.

Se você já tinha uma bancada em uso na referência anterior, confira a orientação abaixo antes de encerrar os emuladores. Primeiro guardamos a sessão; depois atualizamos os arquivos.

Já começou com uma referência que não tinha o comando retomar?

Se npm run retomar informar “Missing script”, não recomece o Café. Essa cópia ainda usa os comandos da referência anterior. Antes de fechar os emuladores antigos, abra outro terminal na mesma raiz, com as ferramentas locais já instaladas, e guarde a sessão:

npx firebase emulators:export ./dados-emuladores --project demo-cafe-aurora-web3

Aguarde a conclusão e confira dados-emuladores/firebase-export-metadata.json. Se já houver uma exportação, confira qual cópia quer preservar antes de confirmar sua substituição. Então encerre o terminal antigo com Ctrl+C.

Compare o package.json e o .gitignore do download desta etapa com os seus. Incorpore os scripts emuladores e retomar e a exclusão de dados-emuladores, preservando as demais configurações. Agora execute npm run retomar e confira o atendimento antes de continuar.

Se os emuladores já estavam fechados e não existe exportação, essa sessão não pode ser recuperada por trocar um comando. O início e o preparo da primeira etapa recriam apenas os dados iniciais; uma imagem ou descrição não exportada terá de ser refeita. Sua aplicação e seus arquivos-fonte continuam preservados.

Continue na sua pasta de trabalho que concluiu a etapa 4 deste percurso. A raiz é o lugar onde aparecem public e cliente-balcao. Não crie uma pasta cafe-aurora-web3 dentro dessa raiz.

Acompanhe em duas janelas

Faça o build. Na janela de operador, entre e mantenha o formulário aberto. Em uma janela privativa, abra a página inicial e use “Acompanhar atualizações”. Depois altere o prazo como operador. A janela do visitante deve receber o aviso sem novo clique.

Conferir cliente-balcao/src/dados.ts

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import { doc, getDocFromServer, onSnapshot, updateDoc } from "firebase/firestore";
import { banco } from "./servico.js";
import { conferirConfiguracao, prepararMensagens } from "./atendimento.js";
import type { Atendimento, Configuracao } from "./atendimento.js";

const referencia = doc(banco, "atendimento", "atual");
export async function obterAtendimento(): Promise<Atendimento> {
  const foto = await getDocFromServer(referencia);
  if (foto.metadata.hasPendingWrites) throw new Error("Aguardando confirmação do serviço.");
  if (!foto.exists()) throw new Error("Prepare o atendimento do exercício.");
  return prepararMensagens(conferirConfiguracao(foto.data()));
}

export async function alterarAtendimento(dados: Configuracao): Promise<void> {
  await updateDoc(referencia, { ...conferirConfiguracao(dados) });
}

export function acompanharAtendimento(apresentar: (dados: Atendimento) => void, falhar: () => void): () => void {
  return onSnapshot(referencia, { includeMetadataChanges: true }, foto => {
    if (foto.metadata.fromCache || foto.metadata.hasPendingWrites) { falhar(); return; }
    try { apresentar(prepararMensagens(conferirConfiguracao(foto.data()))); }
    catch { falhar(); }
  }, falhar);
}

onSnapshot registra a escuta e devolve uma função para encerrá-la. A informação recebida continua passando pela conferência. Os metadados indicam se há gravações pendentes ou uma cópia de cache; nosso texto não trata essas condições como confirmação atual do serviço.

Acompanhar também inclui saber parar

Conferir cliente-balcao/src/main.ts

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

import { obterAtendimento, acompanharAtendimento } from "./dados.js";
import { elemento, apresentar, retirarAviso, comPrazo } from "./tela.js";
import "./operador.js";
if(document.querySelector("#consultar-atendimento")){
const botao = elemento<HTMLButtonElement>("#consultar-atendimento");
const retorno = elemento("#retorno-consulta");
let revisao = 0;
botao.addEventListener("click", async () => {
  const atual = ++revisao;
  botao.disabled = true; retirarAviso(); retorno.textContent = "Consultando o serviço…";
  try { const dados = await comPrazo(obterAtendimento()); if (atual === revisao) { apresentar(dados); retorno.textContent = "Consulta confirmada pelo serviço."; } }
  catch { if (atual === revisao) { retirarAviso(); retorno.textContent = "Não foi possível confirmar. Confira os emuladores e tente novamente."; } }
  finally { if (atual === revisao) { botao.disabled = false; botao.focus(); } }
});

let encerrar: (() => void) | undefined;
const acompanhar = document.querySelector<HTMLButtonElement>("#acompanhar");
acompanhar?.addEventListener("click", () => {
  ++revisao; botao.disabled = false;
  if (encerrar) { encerrar(); encerrar = undefined; retirarAviso(); retorno.textContent = "Acompanhamento encerrado. Consulte para confirmar novamente."; acompanhar.textContent = "Acompanhar atualizações"; return; }
  retirarAviso(); retorno.textContent = "Conectando ao acompanhamento…";
  encerrar = acompanharAtendimento(d => { apresentar(d); retorno.textContent = "Atualização confirmada pelo serviço."; }, () => { retirarAviso(); retorno.textContent = "Sem confirmação atual. A conexão pode estar indisponível."; });
  acompanhar.textContent = "Parar de acompanhar";
});
window.addEventListener("pagehide", () => encerrar?.());

window.addEventListener("offline",()=>{++revisao;botao.disabled=false;retirarAviso();retorno.textContent="Sem conexão. Consulte novamente quando ela voltar.";});
}

O segundo clique encerra a assinatura. O evento pagehide também chama a função de encerramento quando saímos da página. Isso evita manter uma operação que já não atende a uma necessidade da interface.

A variável revisao ajuda a descartar uma consulta antiga que termine depois de outra ação. Sem esse cuidado, uma resposta atrasada poderia sobrescrever uma apresentação mais recente.

Interrompa e recupere

Com o acompanhamento ativo, pare os emuladores. Observe se a interface informa que não confirmou a atualização, em vez de apresentar o prazo anterior como atual. Retome com npm run retomar para importar a sessão exportada. Se a exportação não terminou ou não existe, o preparo recupera apenas as identidades e o atendimento inicial; ele não restaura uma imagem enviada. Pare e inicie novamente o acompanhamento para conferir a recuperação.

Esses emuladores usam dados locais. O comando de início deste percurso exporta ao encerrar com Ctrl+C, e npm run retomar importa essa pasta. Uma interrupção forçada pode impedir a exportação. Confira o retorno do terminal; essa cópia de exercício não é uma política de backup de produção. Use somente os dados fictícios combinados para esta bancada.

O que significa “atual” na sua tela?

Demonstre duas janelas, alteração recebida, encerramento da assinatura, falha e recuperação. Explique por que uma mensagem de cache precisa ser distinguida de uma confirmação do serviço. A próxima informação terá outra natureza: uma imagem deve ser armazenada como arquivo e relacionada ao produto.
