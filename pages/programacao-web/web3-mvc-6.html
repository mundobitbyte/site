Web III · Servidor com Laravel

Uma consulta atravessa serviços

Web III — Em desenvolvimento.

Um cliente pergunta pelo endereço enquanto a equipe confere um CEP. O Café não precisa manter uma cópia de todos os endereços do Brasil. Pode consultar um serviço público e aproveitar somente os campos necessários.

Você já viu o balcão consumir uma API do próprio Café. Agora o servidor PHP será o consumidor de outra API. A diferença traz uma responsabilidade: o serviço externo pode responder com erro, devolver um formato inesperado ou não responder a tempo.

Faça uma consulta pequena

Abra http://localhost:8000/endereco e informe 01001000, o CEP de exemplo da documentação do ViaCEP. O formulário aceita oito algarismos, sem hífen. Essa atividade consulta um endereço; não cria entrega, pedido ou cadastro de cliente.

O ViaCEP documenta consultas em JSON e XML. Vamos usar JSON e poucos testes, sem varreduras de CEPs. Antes de depender da resposta, nosso código confere o formato da entrada.

Conferir app/Services/ConsultaCep.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
namespace App\Services;
use Illuminate\Support\Facades\Http;
use RuntimeException;

class ConsultaCep
{
    public function consultar(string $cep): array
    {
        if (!preg_match('/^[0-9]{8}$/D',$cep)) throw new \InvalidArgumentException('Informe oito algarismos.');
        try { $r=Http::acceptJson()->connectTimeout(2)->timeout(4)->get("https://viacep.com.br/ws/{$cep}/json/"); }
        catch (\Illuminate\Http\Client\ConnectionException $e) { throw new RuntimeException('Consulta indisponível. Tente novamente.',0,$e); }
        $d=$r->json();
        if (!$r->successful() || !is_array($d) || isset($d['erro'])) throw new RuntimeException('CEP não confirmado.');
        foreach (['cep','logradouro','bairro','localidade','uf'] as $campo) {
            if (!isset($d[$campo]) || !is_string($d[$campo])) throw new RuntimeException('Resposta de CEP inválida.');
        }
        return array_intersect_key($d,array_flip(['cep','logradouro','bairro','localidade','uf']));
    }
}

O cliente HTTP do Laravel envia a consulta. connectTimeout(2) limita a espera pela conexão e timeout(4) limita a operação. Esses números são limites escolhidos para a experiência; não garantem que um serviço externo responderá.

Uma resposta HTTP bem-sucedida ainda pode informar um CEP inexistente. Por isso verificamos o campo erro, o tipo da resposta e os campos que realmente serão apresentados. Receber JSON não significa receber informação válida.

Separe consulta e apresentação

A classe ConsultaCep reúne o acesso externo. Antes de acrescentar o novo controller à sua aplicação, execute php artisan make:controller EnderecoController na raiz. Observe o arquivo gerado em app/Http/Controllers: o framework criou um esqueleto, mas ainda não sabe consultar CEP. Complete-o com o código abaixo. Se estiver conferindo o ZIP final, o arquivo já estará completo; compare com o esqueleto, sem sobrescrever sua solução por engano.

O controller recebe o formulário e escolhe como devolver o resultado ou a orientação de falha. A view apresenta texto com escape, preservando o valor digitado quando o usuário precisa corrigir algo.

Conferir app/Http/Controllers/EnderecoController.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
namespace App\Http\Controllers;
use App\Services\ConsultaCep;
use Illuminate\Http\Request;

class EnderecoController
{
    public function mostrar(Request $r, ConsultaCep $consulta)
    {
        $entrada=$r->validate(['cep'=>['nullable','regex:/^[0-9]{8}$/D']]);
        $endereco=null; $falha=null;
        if (isset($entrada['cep'])) {
            try { $endereco=$consulta->consultar($entrada['cep']); }
            catch (\RuntimeException $e) { $falha=$e->getMessage(); }
        }
        return view('endereco',compact('endereco','falha'));
    }
}

Teste oito algarismos para um CEP inexistente, depois uma entrada com letras. Compare as mensagens: um formato recusado pelo Café não é a mesma situação de um endereço não encontrado pelo serviço. Em nenhum caso a página deve inventar um endereço ou continuar mostrando uma consulta anterior como se fosse a nova.

Teste também quando o serviço falha

Não é adequado derrubar um serviço real para testar a nossa recuperação. Os testes abaixo fornecem respostas controladas ao cliente HTTP: resposta válida, estrutura inadequada e erro de conexão. Eles verificam o comportamento do nosso código, sem afirmar que uma chamada real ocorreu.

Conferir tests/Feature/CepTest.php

Caminho a partir da raiz da aplicação. Abra o arquivo no VS Code e compare com a explicação desta etapa.

<?php
namespace Tests\Feature;
use App\Services\ConsultaCep;
use Illuminate\Support\Facades\Http;
use Tests\TestCase;

class CepTest extends TestCase
{
    public function test_contrato_controlado_e_retirada_de_campos_nao_utilizados(): void
    {
        Http::preventStrayRequests();
        Http::fake(['viacep.com.br/*'=>Http::response(['cep'=>'01001-000','logradouro'=>'Praça da Sé','bairro'=>'Sé','localidade'=>'São Paulo','uf'=>'SP','campoPrivado'=>'não devolver'])]);
        $d=app(ConsultaCep::class)->consultar('01001000');
        $this->assertCount(5,$d); $this->assertSame('SP',$d['uf']);
    }
    public function test_falhas_nao_inventam_endereco(): void
    {
        foreach ([Http::response(['erro'=>true]),Http::response('<html>fora do ar</html>',503)] as $r) {
            Http::fake(['viacep.com.br/*'=>$r]);
            $this->get('/endereco?cep=01001000')->assertOk()->assertSee('CEP não confirmado.');
        }
        Http::fake(['viacep.com.br/*'=>Http::failedConnection()]);
        $this->get('/endereco?cep=01001000')->assertSee('Consulta indisponível.');
    }
}

Execute composer test. Se sua rede bloquear a consulta real, a prática de validação e recuperação continua possível com os testes controlados. Registre separadamente “teste automatizado aprovado” e “consulta real realizada”. Uma evidência não substitui a outra.

Quando podemos confiar na apresentação?

Confirme formato, CEP inexistente, resposta inválida e indisponibilidade. Explique por que consultar o serviço no servidor evita colocar futuras credenciais de integração dentro do JavaScript do visitante. Nosso exemplo de ViaCEP não pede chave. Depois dessa consulta entre sistemas, voltaremos ao cliente do Café: como aproveitar recursos do celular sem impedir quem não os tem?
