Etapa 5

Como saber se um arquivo foi alterado?

Use hash para obter evidência de alteração de um arquivo.

O contrato parece igual. Mas é o mesmo arquivo?

Uma pequena mudança pode passar despercebida aos olhos. Precisamos de uma forma de obter uma impressão digital do conteúdo.

Hash e SHA-256

Uma função de hash transforma uma entrada em um valor de tamanho definido. Nesta prática usaremos SHA-256 — Secure Hash Algorithm 256-bit. O objetivo é comparar conteúdos, não “descriptografar” o hash.

Faça você mesmo no PowerShell

  1. Crie a pasta seguranca-mbb.
  2. Dentro dela, crie contrato.txt com Cliente: Alfa e Valor: R$ 5.000,00.
  3. Abra o PowerShell nessa pasta.
  4. Execute:
Get-FileHash .\contrato.txt -Algorithm SHA256

Anote o valor exibido em Hash. Depois troque apenas R$ 5.000,00 por R$ 5.001,00, salve e execute novamente.

Evidência esperada

Mesmo uma alteração pequena produz outro hash. Se dois arquivos tiverem hashes diferentes, seus conteúdos digitais não são idênticos.

Hash de arquivo não é armazenamento de senha

Não conclua que basta aplicar SHA-256 diretamente a senhas. Sistemas modernos usam mecanismos específicos para armazenamento de senha, como Argon2id, bcrypt, scrypt ou PBKDF2, normalmente com um valor aleatório chamado salt.

A seguir: como impedir que outra pessoa leia nossos dados?

O hash ajuda a perceber mudanças, mas não impede a leitura do conteúdo. Precisamos de outra técnica.
