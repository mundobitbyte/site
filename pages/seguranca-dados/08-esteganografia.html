Etapa 8

Como esconder que uma informação existe?

Criptografia tenta impedir a leitura. Esteganografia tenta fazer algo diferente: ocultar a própria existência da mensagem.

Uma mensagem protegida ainda chama atenção

Se alguém encontra um arquivo criptografado, sabe que existe ali algum conteúdo protegido, mesmo sem conseguir lê-lo. Em certas situações, a preocupação pode ser outra: evitar que a presença da mensagem seja percebida.

Esteganografia é a técnica de ocultar uma informação dentro de outro meio, como uma imagem. O objetivo principal não é transformar o conteúdo em algo indecifrável, mas fazê-lo passar despercebido.

Três perguntas, três recursos

Hash: o conteúdo mudou?
Criptografia: quem não possui a chave consegue ler?
Esteganografia: alguém percebe que existe uma mensagem escondida?

Esses recursos podem até ser combinados, mas não devem ser tratados como se fossem a mesma coisa.

Prática orientada com OpenStego

Vamos usar o OpenStego, uma ferramenta gratuita para ocultação de dados em imagens. Baixe a versão adequada no site oficial do OpenStego.

Laboratório, não arquivo pessoal

Use somente uma imagem criada ou copiada para esta atividade. Não utilize documentos, fotos pessoais ou arquivos confidenciais. O objetivo é entender a técnica sem colocar nenhum dado real em risco.

  1. Crie a pasta esteganografia-mbb.
  2. Coloque nela uma imagem de laboratório e renomeie a cópia para imagem-original.png ou imagem-original.jpg.
  3. Crie mensagem.txt com o texto Reunião transferida para 15 horas..
  4. Antes de esconder qualquer coisa, calcule o SHA-256 da imagem original como fez na Etapa 5 e anote o resultado.
  5. Abra o OpenStego no modo Data Hiding e escolha a opção para Embed ou ocultar dados.
  6. Selecione mensagem.txt como arquivo de mensagem e a imagem original como arquivo de cobertura.
  7. Defina um novo nome para a imagem resultante, por exemplo imagem-com-mensagem.png.
  8. Se optar por usar senha, crie uma senha exclusiva para este laboratório.
  9. Execute a operação de ocultação.
  10. Agora use a opção Extract e tente recuperar mensagem.txt a partir da imagem gerada.
  11. Abra o arquivo recuperado e confirme o conteúdo.

Agora volte ao hash — de propósito

Há uma boa razão para repetir o SHA-256 aqui: queremos conectar conceitos, não estudar cada técnica em uma caixa separada.

  1. Calcule o SHA-256 de imagem-com-mensagem.png.
  2. Compare com o hash anotado antes da operação.
  3. Abra as duas imagens e observe se a diferença é evidente apenas olhando para elas.

A imagem pode continuar parecendo comum para uma pessoa, mas o arquivo digital produzido depois da ocultação não é idêntico ao original. O hash torna essa alteração verificável.

Esteganografia não é sinônimo de segurança

Se alguém suspeitar da técnica, pode tentar detectar ou extrair o conteúdo. Ocultar não elimina a necessidade de controles apropriados. Aqui estamos aprendendo a diferença conceitual, não propondo esteganografia como solução universal.

Saímos dos arquivos. Agora vamos olhar para a aplicação.

Até aqui, o usuário usava sistemas já prontos. Mas um sistema também pode criar vulnerabilidades ao tratar incorretamente aquilo que a pessoa digita. Essa é a ponte para SQL Injection.
