## Uso e limites

Extraia o ZIP e abra `Visualg2/visualg.exe`, mantendo as pastas Help e Exemplos. O pacote já contém os arquivos do programa; não há assistente de instalação a seguir. `unins000.exe` é um desinstalador Inno Setup, não o programa da aula.

A ajuda histórica cita Windows 95 ou posterior. Isso não comprova compatibilidade com Windows 10/11. Não houve execução do binário neste Linux nem varredura por antivírus. Analise o arquivo com proteção atualizada e use um computador aprovado para a aula; não desative proteções para contornar bloqueios.
