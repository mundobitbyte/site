Privacidade em linguagem simples

Dados usados para continuar sua aprendizagem

O que é armazenado

Nome, e-mail, identificador interno da conta, curso, aulas iniciadas ou concluídas, checkpoints, pontos derivados de atividades únicas, conquistas e última posição estudada.

Para quê

Permitir login, recuperar a conta, mostrar o progresso e continuar em outro dispositivo. Os dados não são usados para ranking público.

O que não solicitamos

CPF, telefone, endereço ou data de nascimento completa não são necessários nesta etapa.

Exclusão

A estrutura mantém os dados de cada pessoa dentro do próprio identificador de usuário. Para solicitar exclusão da conta e do progresso, use o canal de contato do Mundo bit Byte. A administração apagará os dados educacionais e a conta de autenticação correspondente.

Segurança

Cada aluno só pode ler e alterar os próprios dados. Senhas são tratadas pelo Firebase Authentication; nunca envie senha, token ou segredo pelo contato ou por mensagens.
