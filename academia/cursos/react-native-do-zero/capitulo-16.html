O aplicativo chega ao celular

No capítulo anterior, o projeto passou a existir no computador. Agora falta confirmar a consequência mais importante dessa mudança: o aplicativo precisa abrir e funcionar em um aparelho real.

Construa e confira

1. O computador serve o projeto; o celular executa

Durante o desenvolvimento, npx expo start inicia um servidor no computador. O Expo Go no celular abre o projeto por meio do QR code apresentado no terminal.

Construa e confira

2. Prepare o aparelho

•instale o Expo Go em um aparelho Android;

•mantenha computador e celular, de preferência, na mesma rede Wi-Fi;

•abra o Expo Go antes de escanear o QR code.

Construa e confira

3. Inicie o projeto local

Terminal
cd santa-filomena-app
npx expo start

O terminal exibirá um QR code. No Android, use a opção Scan QR code do Expo Go.

Construa e confira

4. Se a rede local impedir a conexão

Em algumas redes, o roteador impede que celular e computador se encontrem. Antes de alterar o projeto, teste o modo tunnel:

Terminal
npx expo start --tunnel

Use essa alternativa somente quando a conexão local não funcionar. A troca de modo de conexão não muda o código do aplicativo.

Construa e confira

5. Faça o percurso completo no aparelho

1.Escolha água e gás.

2.Altere quantidades.

3.Avance para Dados do cliente.

4.Preencha nome e telefone.

5.Avance para Endereço.

6.Preencha rua, número e bairro.

7.Abra a revisão.

8.Confirme itens, quantidades, total, cliente e endereço.

9.Envie o pedido de demonstração.

10.Confirme a resposta da API de testes.

11.Volte entre as telas e confira que os dados permanecem.

Construa e confira

6. O que deve permanecer igual ao Snack

•identidade visual;

•produtos e valores didáticos;

•regras de seleção e quantidade;

•estado preservado entre telas;

•revisão do pedido;

•requisição POST de demonstração.

Se o comportamento mudar, o primeiro objetivo é descobrir a causa. Não adapte o livro para esconder um erro de ambiente ou uma dependência ausente.

Checkpoint

7. Checkpoint 16 - O projeto roda no celular

•mesmo código do Checkpoint 15;

•execução confirmada no Expo Go;

•evidência do fluxo completo em aparelho real;

•registro do modo de conexão usado: LAN ou tunnel.

Construa e confira

8. O próximo problema já apareceu

O aplicativo já funciona no celular, mas ainda aparece como um projeto aberto pelo Expo Go. Ele precisa ganhar identidade própria antes de se tornar um aplicativo instalável independente.

Capítulo 16 concluído

Marque a conclusão somente depois de copiar o código, observar a prévia e realizar os testes indicados.
