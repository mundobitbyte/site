Capítulo 2

O aplicativo ganha sua própria interface

No capítulo anterior, o projeto deixou de ser apenas o exemplo original do Snack. Agora vamos começar a construir uma interface realmente pensada para a Água & Gás Santa Filomena.

Como ler os códigos deste capítulo

Em cada etapa prática, o quadro mostra o arquivo completo naquele momento. Dentro do mesmo quadro, somente as linhas destacadas são as que você deve digitar ou alterar naquela etapa.

1. Onde paramos

Não precisamos rever todos os códigos do capítulo anterior. Basta lembrar a pequena estrutura que já existe:

App.js components/ IdentidadeEmpresa.js assets/ agua-gas.png

O App.js organiza a tela. O componente IdentidadeEmpresa já existe e, neste momento, apresenta a imagem da empresa.

2. Observe antes de mexer

Olhe a pré-visualização do aplicativo e tente identificar o fundo, o nome da empresa, a área onde a imagem aparece e os espaços entre esses elementos.

A primeira pergunta é simples

O que podemos mudar primeiro para a tela começar a deixar de parecer o exemplo original?

Vamos começar pelo que envolve toda a interface: o fundo.

3. Primeira mudança: o fundo

Abra App.js. O arquivo inteiro aparece abaixo para você não precisar adivinhar onde está a alteração. Altere somente a linha destacada.

App.js — altere somente a linha destacada
import * as React from 'react';
import { Text, View, StyleSheet } from 'react-native';
import Constants from 'expo-constants';
import { Card } from 'react-native-paper';

import IdentidadeEmpresa from './components/IdentidadeEmpresa';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.paragraph}>
        Água & Gás Santa Filomena
      </Text>

      <Card>
        <IdentidadeEmpresa />
      </Card>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    paddingTop: Constants.statusBarHeight,
    backgroundColor: '#eef3f7',
    padding: 8,
  },

  paragraph: {
    margin: 24,
    fontSize: 18,
    fontWeight: 'bold',
    textAlign: 'center',
  },
});

Destaque = linha que deve ser alterada agora.

Depois da alteração, observe a pré-visualização

A estrutura não mudou. O conteúdo também não. Apenas o fundo passou a ter outra aparência.

Um estilo pode mudar a aparência de um componente sem mudar aquilo que ele contém.

4. O conteúdo precisa de uma área própria

O fundo mudou, mas o conteúdo ainda está dentro do Card que veio no exemplo. Queremos começar a controlar essa área por conta própria.

Antes de digitar

Apague a linha import { Card } from 'react-native-paper';. Depois, substituiremos o Card por uma View nossa.

No quadro abaixo, o arquivo inteiro já aparece no novo estado. Digite ou ajuste somente as linhas destacadas.

App.js — digite/ajuste as linhas destacadas
import * as React from 'react';
import { Text, View, StyleSheet } from 'react-native';
import Constants from 'expo-constants';

import IdentidadeEmpresa from './components/IdentidadeEmpresa';

export default function App() {
  return (
    <View style={styles.container}>
      <Text style={styles.paragraph}>
        Água & Gás Santa Filomena
      </Text>

      <View style={styles.cartao}>
        <IdentidadeEmpresa />
      </View>
    </View>
  );
}

const styles = StyleSheet.create({
  container: {
    flex: 1,
    justifyContent: 'center',
    paddingTop: Constants.statusBarHeight,
    backgroundColor: '#eef3f7',
    padding: 16,
  },

  paragraph: {
    margin: 24,
    fontSize: 18,
    fontWeight: 'bold',
    textAlign: 'center',
  },

  cartao: {
    backgroundColor: '#ffffff',
    borderRadius: 16,
    padding: 20,
  },
});
  • backgroundColor define o fundo do cartão;
  • borderRadius arredonda seus cantos;
  • padding cria espaço entre a borda e o conteúdo.
Observe a pré-visualização

A área branca que envolve o conteúdo agora foi construída por nós. As propriedades apareceram porque a interface passou a precisar delas.

5. Nome e imagem pertencem ao mesmo conjunto

Agora olhe novamente para a tela. O nome da empresa aparece acima do cartão, enquanto a imagem está dentro de IdentidadeEmpresa.

Visualmente, porém, nome e imagem fazem parte da mesma apresentação da empresa. Esse é o momento em que o componente criado no capítulo anterior passa a ter uma função mais clara.

Vamos mover o nome para components/IdentidadeEmpresa.js.

Primeiro, no App.js

Apague o bloco Text que mostra “Água & Gás Santa Filomena” e retire Text da linha de importação. Como nesta operação estamos apenas apagando, não há linha nova destacada.

6. A identidade precisa de hierarquia visual

Nome e imagem já estão juntos. Agora precisamos organizar melhor essa apresentação: o nome deve ter uma área de destaque e a imagem precisa ocupar um espaço previsível.

Continue em components/IdentidadeEmpresa.js. Neste passo, o espaçamento do título passará a ser controlado pela nova barra superior; por isso, apague marginBottom: 16 do estilo titulo. O quadro abaixo mostra o estado final.

IdentidadeEmpresa.js — digite/ajuste as linhas destacadas
import * as React from 'react';
import { View, Text, Image, StyleSheet } from 'react-native';

export default function IdentidadeEmpresa() {
  return (
    <View style={styles.identidade}>
      <View style={styles.barraSuperior}>
        <Text style={styles.titulo}>
          Água & Gás Santa Filomena
        </Text>
      </View>

      <Image
        source={require('../assets/agua-gas.png')}
        style={styles.imagem}
        resizeMode="contain"
      />
    </View>
  );
}

const styles = StyleSheet.create({
  identidade: {
    alignItems: 'center',
  },

  barraSuperior: {
    width: '100%',
    backgroundColor: '#dbeafe',
    paddingVertical: 12,
    borderRadius: 12,
    marginBottom: 16,
  },

  titulo: {
    fontSize: 24,
    fontWeight: 'bold',
    textAlign: 'center',
  },

  imagem: {
    width: '100%',
    height: 180,
  },
});
  • barraSuperior cria uma área própria para o nome;
  • width e height reservam o espaço da imagem;
  • resizeMode="contain" ajuda a manter a imagem inteira dentro desse espaço.
IdentidadeEmpresa ├── barraSuperior │ └── titulo └── imagem
Observe a pré-visualização e compare

Cada estrutura apareceu porque a interface passou a precisar dela.

8. O que construímos

O mapa abaixo representa a composição que estamos construindo. As cores e medidas finais ainda serão confirmadas na validação prática no Snack.

TELA └── cartão └── IdentidadeEmpresa ├── Água & Gás Santa Filomena ├── [ IMAGEM ] ├── Água mineral e gás com entrega └── Peça com praticidade e acompanhe sua entrega.

O importante é reconhecer a sequência visual: tela → cartão → identidade da empresa → título, imagem e informações.

9. Experimente para entender

Antes de encerrar, vamos fazer um pequeno teste para enxergar melhor o efeito de uma propriedade.

Abra App.js. No quadro abaixo, altere somente a linha destacada e observe os cantos do cartão.

App.js — experimento temporário
import * as React from 'react';
import { View, StyleSheet } from 'react-native';

12. O que aprendemos

Os conceitos deste capítulo surgiram porque a interface precisou deles:

  • View para criar áreas da interface;
  • Text para apresentar informações;
  • Image para apresentar a imagem;
  • StyleSheet para organizar estilos;
  • backgroundColor, padding e borderRadius para construir a área visual;
  • fontSize, fontWeight e textAlign para criar hierarquia;
  • width, height e resizeMode para controlar a imagem.

Também começamos a perceber que componentes podem reunir partes da interface que pertencem ao mesmo conjunto.

13. Confira antes de encerrar

  • O nome e a imagem agora fazem parte de IdentidadeEmpresa.
  • A apresentação da empresa possui título, imagem, descrição e mensagem.
  • Nos quadros de código, consigo identificar que apenas as linhas destacadas são as que devo digitar ou alterar naquela etapa.
