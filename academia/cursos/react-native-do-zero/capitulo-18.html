Construa e confira

1. Desenvolvimento e instalação são coisas diferentes

Artefato de teste

O perfil preview com android.buildType: "apk" gera um arquivo instalável diretamente no aparelho.

Expo Go é excelente para desenvolver e testar. Um usuário final, porém, não deveria depender dele. Para uma instalação direta no Android, precisamos gerar um APK.

Construa e confira

2. Entre no serviço de build da Expo

Terminal
npm install --global eas-cli
eas login
eas whoami

A conta usada pode ser a mesma conta Expo criada no início do curso.

Construa e confira

3. Defina a identificação Android

No app.json, acrescente um identificador de aplicativo. Para o projeto didático deste curso, usaremos:

app.json — arquivo completo com identificação Android
{
  "expo": {
    "name": "Santa Filomena Água & Gás",
    "slug": "santa-filomena-agua-e-gas",
    "version": "1.0.0",
    "orientation": "portrait",
    "icon": "./assets/icon.png",
    "userInterfaceStyle": "light",
    "plugins": [
      [
        "expo-splash-screen",
        {
          "image": "./assets/splash-icon.png",
          "imageWidth": 200,
          "resizeMode": "contain",
          "backgroundColor": "#eef3f7"
        }
      ]
    ],
    "android": {
      "package": "com.mundobitbyte.santafilomena"
    }
  }
}

Esse identificador pertence ao aplicativo Android e não é o nome mostrado ao usuário.

Construa e confira

4. Configure o EAS Build

Terminal
eas build:configure -p android

O comando cria ou atualiza eas.json. Para este percurso, configure um perfil de preview que produza um APK instalável.

eas.json - configuração mínima deste percurso
{
  "build": {
    "preview": {
      "distribution": "internal",
      "android": {
        "buildType": "apk"
      }
    },
    "production": {}
  }
}
Construa e confira

5. Gere o APK

Terminal
eas build -p android --profile preview

O build ocorre na infraestrutura da Expo. Na primeira execução, o EAS pode pedir confirmação ou criação das credenciais de assinatura Android. Para este projeto didático, escolha a opção de deixar o serviço gerenciar as credenciais.

Construa e confira

6. Instale no aparelho

Quando o build terminar, abra a página do build indicada pelo EAS e use a opção de instalação no aparelho Android. O perfil internal/preview gera um APK apropriado para instalação direta.

Construa e confira

7. O teste que fecha o volume

1.Feche o Expo Go.

2.Encerre o servidor npx expo start no computador.

3.Abra o aplicativo Santa Filomena Água & Gás pelo ícone instalado no Android.

4.Observe a abertura e valide a identidade visual nativa.

5.Percorra produtos, cliente, endereço e revisão.

6.Execute o envio de demonstração.

7.Feche e abra o aplicativo novamente.

Construa e confira

8. APK não é o mesmo que publicação na loja

O APK deste capítulo serve para instalação e validação interna. Para publicar um novo aplicativo na Google Play, o fluxo de produção normalmente usa Android App Bundle (AAB) e ainda envolve cadastro, políticas, ficha da loja e processo de distribuição. Isso não é necessário para provar o objetivo deste volume: gerar e instalar o aplicativo construído.
