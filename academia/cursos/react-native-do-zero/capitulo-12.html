Construa e confira

1. O problema não está na falta de dados

Produtos guarda itens e quantidades. DadosCliente guarda nome e telefone. EnderecoEntrega guarda o endereço. Cada parte funciona, mas nenhuma delas enxerga o pedido completo.

Produtos → itens, quantidades e valores→DadosCliente → nome e telefone→EnderecoEntrega → local da entrega→Quem consegue reunir tudo isso para uma revisão?

Poderíamos copiar informações de um componente para outro, mas isso criaria memórias duplicadas e difíceis de manter sincronizadas. O caminho mais seguro é fazer o estado subir para um componente comum.

Construa e confira

2. Surge uma nova responsabilidade: Pedido

App.js organiza a tela inteira. IdentidadeEmpresa apresenta a empresa. Agora existe uma terceira responsabilidade concreta: organizar tudo o que pertence ao pedido.

App.js → estrutura geral da tela→IdentidadeEmpresa.js → identidade da empresa→Pedido.js → dados e partes que formam o pedido

Crie components/Pedido.js. Neste primeiro momento, ele apenas passa a existir como o lugar que, nas próximas etapas, reunirá os estados já usados pelo projeto.

5. Produtos passa a receber o estado que antes era só dele

O catálogo continua responsável por escolher, aumentar e diminuir itens. A diferença é que a lista itensPedido agora chega de Pedido.js.

Quando Produtos precisa alterar essa lista, usa onAtualizarItens. Assim, a regra continua perto dos produtos, mas a memória pertence ao pedido inteiro.

components/Produtos.js - arquivo completo; ajuste as linhas em negrito
import * as React from 'react';
import { View, Text, StyleSheet } from 'react-native';
import Produto from './Produto';

export default function Produtos(props) {
  const { produtos, itensPedido, onAtualizarItens } = props;

  function alternarProduto(id) {
    const itemExistente = itensPedido.find(
      (item) => item.id === id
    );

    if (itemExistente) {
      const novaLista = itensPedido.filter(
        (item) => item.id !== id
      );
      onAtualizarItens(novaLista);
    } else {
      onAtualizarItens([
        ...itensPedido,
        { id: id, quantidade: 1 },
      ]);
    }
  }

  function aumentarQuantidade(id) {
    const novaLista = itensPedido.map((item) => {
      if (item.id === id) {
        return {
          ...item,
          quantidade: item.quantidade + 1,
        };
      }
      return item;
    });
    onAtualizarItens(novaLista);
  }

  function diminuirQuantidade(id) {
    const novaLista = itensPedido.map((item) => {
      if (item.id === id && item.quantidade > 1) {
        return {
          ...item,
          quantidade: item.quantidade - 1,
        };
      }
      return item;
    });
    onAtualizarItens(novaLista);
  }
  const totalPedido = itensPedido.reduce((total, item) => {
    const produto = produtos.find(
      (produto) => produto.id === item.id
    );
    return total + produto.preco * item.quantidade;
  }, 0);

  return (
    <View style={styles.areaProdutos}>
      <Text style={styles.tituloSecao}>Produtos</Text>

      <Text style={styles.resumo}>
        Tipos selecionados: {itensPedido.length}
      </Text>

      <Text style={styles.total}>
        Total do pedido: R$ {totalPedido.toFixed(2).replace('.', ',')}
      </Text>
      {produtos.map((produto) => {
        const itemPedido = itensPedido.find(
          (item) => item.id === produto.id
        );

        return (
          <Produto
            key={produto.id}
            nome={produto.nome}
            descricao={produto.descricao}
            preco={produto.preco}
            selecionado={itemPedido !== undefined}
            quantidade={itemPedido ? itemPedido.quantidade : 0}
            onAlternar={() => alternarProduto(produto.id)}
            onAumentar={() => aumentarQuantidade(produto.id)}
            onDiminuir={() => diminuirQuantidade(produto.id)}
          />
        );
      })}
    </View>
  );
}

const styles = StyleSheet.create({
  areaProdutos: {
    marginTop: 24,
  },
  tituloSecao: {
    fontSize: 20,
    fontWeight: 'bold',
    marginBottom: 12,
  },
  resumo: {
    color: '#374151',
    fontSize: 14,
    marginBottom: 4,
  },

8. Agora a revisão finalmente pode existir

Só depois dessa reorganização temos um lugar que conhece todas as informações. Agora faz sentido criar o componente RevisaoPedido.

Crie components/RevisaoPedido.js e use o código abaixo.

components/RevisaoPedido.js - arquivo novo; digite todo o conteúdo em negrito
import * as React from 'react';
import { View, Text, StyleSheet } from 'react-native';

export default function RevisaoPedido(props) {
  const itensDetalhados = props.itensPedido.map((item) => {
    const produto = props.produtos.find(
      (produto) => produto.id === item.id
    );

    return {
      ...item,
      nome: produto.nome,
      preco: produto.preco,
      subtotal: produto.preco * item.quantidade,
    };
  });
  const totalPedido = itensDetalhados.reduce(
    (total, item) => total + item.subtotal,
    0
  );

  const endereco = [
    props.rua,
    props.numero,
    props.bairro,
    props.complemento,
  ]
    .filter((parte) => parte.trim() !== '')
    .join(', ');

  return (
    <View style={styles.areaRevisao}>
      <Text style={styles.tituloSecao}>Revise seu pedido</Text>
      <Text style={styles.subtitulo}>Itens</Text>
      {itensDetalhados.length === 0 ? (
        <Text style={styles.aviso}>Nenhum produto selecionado.</Text>
      ) : (
        itensDetalhados.map((item) => (
          <Text key={item.id} style={styles.linha}>
            {item.quantidade} x {item.nome} - R$ {item.subtotal
              .toFixed(2)
              .replace('.', ',')}
          </Text>
        ))
      )}

      <Text style={styles.total}>
        Total: R$ {totalPedido.toFixed(2).replace('.', ',')}
      </Text>
      <Text style={styles.subtitulo}>Cliente</Text>
      <Text style={styles.linha}>
        {props.nome.trim() !== '' ? props.nome : 'Nome não informado'}
      </Text>
      <Text style={styles.linha}>
        {props.telefone.trim() !== ''
          ? props.telefone
          : 'Telefone não informado'}
      </Text>

      <Text style={styles.subtitulo}>Entrega</Text>
      <Text style={styles.linha}>
        {endereco !== '' ? endereco : 'Endereço não informado'}
      </Text>
    </View>
  );
}

9. O que a revisão faz com os dados

•map transforma os itens escolhidos em itens com nome, preço e subtotal;

•reduce calcula o total a partir desses subtotais;

•filter remove partes vazias do endereço;

•join une as partes restantes em uma única linha;

•as condições exibem mensagens claras quando alguma informação ainda não foi preenchida.

Nada disso cria uma segunda versão do pedido. A revisão apenas lê o estado atual e apresenta outra visão dele.

11. O que mudou para o usuário

Antes, o cliente precisava percorrer a tela e lembrar o que havia preenchido. Agora existe uma área específica para conferência.

•itens e quantidades aparecem juntos;

•o total pode ser conferido;

•nome e telefone aparecem na mesma revisão;

•o endereço é apresentado em uma linha organizada;

•alterações feitas acima se refletem automaticamente na revisão.

O sistema ainda não enviou nada. Neste capítulo, a conquista é permitir uma conferência confiável antes da próxima ação.

      ...item,
      nome: produto.nome,
      preco: produto.preco,
      subtotal: produto.preco * item.quantidade,
    };
  });
  const totalPedido = itensDetalhados.reduce(
    (total, item) => total + item.subtotal,
    0
  );

  const endereco = [
    props.rua,
    props.numero,
    props.bairro,
    props.complemento,
  ]
    .filter((parte) => parte.trim() !== '')
    .join(', ');

  return (
    <View style={styles.areaRevisao}>
      <Text style={styles.tituloSecao}>Revise seu pedido</Text>
      <Text style={styles.subtitulo}>Itens</Text>
      {itensDetalhados.length === 0 ? (
        <Text style={styles.aviso}>Nenhum produto selecionado.</Text>
      ) : (
        itensDetalhados.map((item) => (
          <Text key={item.id} style={styles.linha}>
            {item.quantidade} x {item.nome} - R$ {item.subtotal
              .toFixed(2)
              .replace('.', ',')}
          </Text>
        ))
      )}

      <Text style={styles.total}>
        Total: R$ {totalPedido.toFixed(2).replace('.', ',')}
      </Text>
      <Text style={styles.subtitulo}>Cliente</Text>
      <Text style={styles.linha}>
        {props.nome.trim() !== '' ? props.nome : 'Nome não informado'}
      </Text>
      <Text style={styles.linha}>
        {props.telefone.trim() !== ''
          ? props.telefone
          : 'Telefone não informado'}
      </Text>

      <Text style={styles.subtitulo}>Entrega</Text>
      <Text style={styles.linha}>
        {endereco !== '' ? endereco : 'Endereço não informado'}
      </Text>
    </View>
  );
}

14. O que aprendemos

•quando vários componentes precisam compartilhar informações, o estado pode subir para um componente comum;

•um componente pode ser responsável pelos dados sem assumir toda a interface;

•props podem levar valores e funções para componentes filhos;

•uma revisão deve derivar informações do estado atual, não copiar o pedido para outro estado;

•map, reduce, filter e join podem reaparecer quando o problema realmente exige transformar ou reunir dados;

•organização de componentes também é uma decisão de projeto, não apenas uma escolha estética.
