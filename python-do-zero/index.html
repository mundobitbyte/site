O que é um checkpoint?

É uma fotografia funcional do projeto em um ponto específico da evolução. Serve para conferir o código, retomar o estudo ou começar diretamente no estágio indicado pelo livro.

Como usar

  1. Localize no livro o checkpoint relacionado ao capítulo estudado.
  2. Extraia o ZIP e abra a pasta do checkpoint no VS Code.
  3. Leia o README, execute e compare com o que você construiu.
