<h3 id="passo-2">De uma lista de dados para uma lista de componentes</h3>
<p>O arquivo de apoio também contém funções para a sessão e a edição que utilizaremos mais adiante. Nesta consulta, acompanhe somente o pedido público, a conferência do produto e <code>lerProdutos</code>; não é preciso memorizar as operações que ainda não usamos. A função <code>lerProdutos</code> confere cada item recebido antes de devolver um <code>Produto[]</code>. O tipo TypeScript ajuda o desenvolvimento, mas é essa conferência que recusa uma estrutura inesperada em tempo de execução.</p>

<p>Em JSX, <code>className</code> ocupa o papel do atributo HTML <code>class</code>; as classes continuam ligando o artigo ao CSS conhecido. <code>map</code> transforma cada produto em um artigo. A propriedade <code>key</code> usa seu identificador estável para que React acompanhe os itens; a posição na lista não identifica um produto. As fotos e os textos alternativos vêm do mesmo Café. O preço inteiro em centavos é dividido por 100 apenas na formatação em reais.</p>
