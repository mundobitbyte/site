<p>O balcão já consulta o aviso sem recarregar a página. Marina quer acrescentar uma orientação de retirada e, depois, permitir consultas ao cardápio na mesma área. Se continuarmos distribuindo mudanças de texto e visibilidade pelo arquivo inteiro, ficará difícil saber qual parte da interface cada função controla.</p>
<p>Vamos experimentar React em uma área delimitada: o balcão. A página inicial, o cardápio anterior e o sistema de mensagens continuam existindo. Você não vai converter o Café inteiro nem precisa ter concluído o módulo de React Native.</p>
<h3 id="passo-1">Faça uma orientação aparecer</h3>
<p>Preserve sua pasta final do Capítulo 2. Acrescente os arquivos de apoio do download e compare <code>public/balcao.php</code>: o lugar que React controlará é <code>&lt;div id="cafe-app"&gt;</code>. O restante da página continua sendo HTML/PHP.</p>
<p><strong>React</strong> é uma biblioteca para construir interfaces por componentes. Um componente descreve uma parte da apresentação. Nesta primeira experiência ele recebe um título e um texto e devolve a orientação que veremos no navegador.</p>
{{arquivo:cliente-balcao/src/App.tsx}}
<p><code>OrientacaoProps</code> é uma interface TypeScript para os valores recebidos, chamados <em>props</em>. A função <code>Orientacao</code> usa esses valores. A sintaxe parecida com HTML se chama JSX; com TypeScript, o arquivo recebe extensão <code>.tsx</code>. É sintaxe processada pelo build, não HTML colocado dentro de uma string.</p>
<p>Troque apenas o texto da orientação por uma frase útil para a retirada. Antes de acrescentar outra funcionalidade, vamos ver essa pequena mudança funcionando.</p>
<h3 id="passo-2">O editor continua sendo o VS Code</h3>
<p>Você escreve TSX no VS Code. npm instala as dependências; Vite transforma os arquivos-fonte em JavaScript para o navegador. São papéis diferentes. Continue com Node 24, já preparado no TypeScript Essencial, e execute em <code>cliente-balcao</code>:</p>
<pre class="code-block"><code>npm ci
npm run build</code></pre>
<p>Na raiz, inicie <code>php -d opcache.enable=0 -S localhost:8000 -t public</code> e abra <code>http://localhost:8000/balcao.php</code>. O texto precisa aparecer dentro do balcão. Alterou TSX? Novo build e recarregamento. Não estamos usando Live Preview para executar PHP nem o servidor de desenvolvimento do Vite para substituir o servidor PHP.</p>
{{arquivo:cliente-balcao/src/main.tsx}}
<p>Na função <code>Orientacao</code>, <code>{titulo,texto}</code> retira duas propriedades do objeto recebido. É uma desestruturação: poderíamos receber <code>props</code> e ler <code>props.titulo</code> e <code>props.texto</code>. <code>export</code> disponibiliza <code>App</code> para o arquivo que a importa.</p>
<p><code>createRoot</code> liga React ao elemento <code>cafe-app</code> e <code>render</code> apresenta <code>App</code>. O antigo <code>main.ts</code> foi preservado como referência em <code>main-anterior.ts.txt</code>. Ele não deve continuar controlando os elementos que React passará a renderizar. Preserve sua versão anterior com esse nome e retire <code>src/main.ts</code>; o novo arquivo de entrada é <code>src/main.tsx</code>. Os imports que terminam em <code>.js</code> são resolvidos pelo TypeScript/Vite a partir dos fontes: não crie cópias JavaScript à mão.</p>
