# Referência do esqueleto

Configurações, bootstrap, front controller e entrada Artisan adaptados do esqueleto oficial laravel/laravel, branch 13.x, licença MIT. Código do framework permanece em vendor após composer install. Arquivos de configuração de agentes e ferramentas de IA do esqueleto não fazem parte do material didático. Não execute composer setup de outra referência: siga os comandos desta aula.
